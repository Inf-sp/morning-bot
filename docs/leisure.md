# 🍿 Досуг

## Назначение

Один хаб вместо четырёх разделов Кино, Музыка, Книги и Игры. Открывается кнопкой
`🍿 Досуг` главного меню (`m_leisure`) мгновенно: экран собирается только из готовых
кэшей, без сети и AI.

## Экран хаба

```text
🍿 Досуг

🎫 Концерты
• Muse · рок · 12 октября

🎟️ Премьеры кино
• «Название» · жанр · 16 октября · ⭐ 7.8/10

📚 Новые книги
• «Название» · жанр · 1 сентября · ⭐ 4.2/5

👾 Новые игры
• Название · жанр · дата · платформы
```

- После заголовка и между блоками одна пустая строка; в каждом блоке до трёх пунктов (одна строка
  на пункт, `·` для метаданных). Пустой блок скрыт целиком.
- Название — ссылка там, где она есть на полных экранах: билеты концерта, трейлер
  фильма (или страница TMDb), Google Books, трейлер или источник игры. Превью ссылок
  отключено.
- Дата во всех блоках пишется как у концертов: `16 октября`, год — только если он не
  текущий (`3 февраля 2027`). Для кино — дата выхода в стране пользователя, для книг —
  дата публикации, для игр — дата релиза.
- Если все блоки пусты, под заголовком одна строка-подсказка.

Источники блоков (только чтение кэша):

| Блок | Кэш |
|---|---|
| 🎫 Концерты | персональный кэш концертов любимых артистов, ближайшие 62 дня |
| 🎟️ Премьеры кино | недельная витрина премьер страны пользователя (допускается прошлая) |
| 📚 Новые книги | витрина книжных премьер месяца (допускается устаревшая) |
| 👾 Новые игры | сезонная витрина игр по платформам пользователя, тройка по кругу на день |

## Кнопки

Четыре зелёных пункта в один столбец, последней строкой — `#️⃣ Главная | 🎚️ Настроить`:

```text
🎬 Подобрать кино      → movie_reco: карточка фильма дня
📚 Подобрать книгу        → book_reco: карточка книги дня
👾 Подобрать игру     → vg_reco: игра недели
🎧 Подобрать музыку       → music_reco: артист дня
#️⃣ Главная | 🎚️ Настроить  → m_menu | lz_lib (экран «Моя библиотека»)
```

Кнопки «Премьеры и концерты» нет: премьеры и концерты видны прямо на главном экране,
концерты с выбором страны — в «Моей библиотеке», новинки — в выборе жанра под карточкой. Старые кнопки
премьер (`lz_prem`, `movie_premieres`, `book_premieres`, `vg_premieres`) из истории чата
продолжают работать.

### Карточки рекомендаций

Единый порядок кнопок под карточками фильма, книги, игры и артиста:

```text
✨ Другой фильм / Другая книга / Другая игра / Другой артист   ← зелёная
🎲 Настолки                                                    ← только у игр
Не нравится                                                    ← красная
⬅️ Назад | #️⃣ Главная
```

Отдельной кнопки «Выбрать жанр» нет. `✨ Другой …` (`movie_pick_*`, `book_pick_*`,
`vg_pick`/`vg_pick_b`, `music_pick`) не присылает карточку сразу, а меняет кнопки под текущей
карточкой на выбор (все пункты зелёные, по одному в строке):

```text
Любой жанр           ← прежний «Другой …»: подбор по вкусу без ограничения жанра
🆕 Новинка           ← не у настолок
Комедия / Фэнтези / RPG / Инди …
⬅️ Назад | #️⃣ Главная   ← «Назад» возвращает прежние кнопки карточки
```

Выбор присылает новую карточку отдельным сообщением, у прежней карточки кнопки снимаются —
она остаётся в истории. Подбор внутри жанра опирается на «Мою библиотеку»: кино ранжируется
по профилю вкуса из «Моего кино», книги подбирает AI по «Моим книгам» внутри жанра (без AI —
книги жанра из Google Books), музыка — по «Моим артистам», игры — с учётом жанров «Моего
набора игр». Старые кнопки «Выбрать жанр» из истории чата продолжают работать.

`Не нравится` (`movie_no_*`, `book_no_*`, `game_no`, `listen_no`) отправляет текущую
рекомендацию в общий стоп-лист — она больше не показывается — и сразу открывает
следующую. Добавление в «Моё кино / Мои книги / Мой набор игр / Мои артисты» — через
«Мою библиотеку».

### 🆕 Новинка

В выборе жанра кино, книг, игр (не настолок) и музыки второй строкой стоит зелёная
`🆕 Новинка` (`nov_movie`, `nov_book`, `nov_game`, `nov_music`, модуль `leisure_novelty.py`).
Она показывает одну новинку отдельной карточкой с картинкой:

- кино — из недельных премьер TMDB страны пользователя: `🎬 Сейчас в кино` или
  `🎬 Скоро в кино · 16 октября`, название-ссылка, жанры, описание (без оценок);
- книги — из витрины книжных премьер: `📚 Новая книга · 1 сентября`, автор и жанр, описание;
- игры — из витрины игровых премьер: `👾 Вышла …` / `👾 Выходит …`, жанр и платформы, описание;
- музыка — свежий альбом (за последние 90 дней) выбранных жанров из открытой ленты
  Apple Music страны пользователя (`apple_music.py`): `🎧 Новый альбом · 2 октября`,
  `«Альбом» — Артист`. Релизы не придумываются AI.

Под карточкой: `✨ Другой фильм` (и т. п.) — тот же выбор жанра под карточкой, где
`🆕 Новинка` даёт следующую новинку без повторов; красная `Не нравится` (новинка уходит в
стоп-лист; у музыки скрывается альбом, а не артист); `⬅️ Назад | #️⃣ Главная`. Если новинок
нет — короткая строка и сразу выбор жанра.

### 🎚️ Моя библиотека

`🎬 Кино` («🎚️ Моё кино»), `📚 Книги` («🎚️ Мои книги»), `👾 Игры` («🎚️ Мой набор игр»),
`🎧 Музыка` («🎚️ Мои артисты»), `🎫 Концерты` (концерты любимых артистов с выбором
страны), `⬅️ Назад` → хаб | `#️⃣ Главная`. Данные списков не менялись; `⬅️ Назад`
этих экранов, связанных коллекций и концертов ведёт в библиотеку.

## Кэш и прогрев

Ночной прогрев `leisure` идёт в 00:15 (после Обучения, до финального «Моего дня»
в 00:20) и повторяется в 03:00 и 06:00, если кэш не готов. Он по очереди:

1. обновляет концерты любимых артистов, только если персональный кэш устарел;
2. обновляет премьеры кино, только если нет витрины текущей недели;
3. книжные и сезонные игровые премьеры (свежий кэш возвращается без запроса);
4. готовит карточку фильма дня для `🎬 Подобрать кино`.

Ошибка одного шага не мешает остальным. Хаб считается готовым, когда есть свежие
премьеры кино, книг, игр и карточка фильма дня. Книга и артист дня кэшируются при
первом открытии; игра недели подбирается локально без AI.

## Старые кнопки

`m_movie`, `m_music`, `m_books`, `m_games`, `movie_now_playing`, `a_watch`, `a_read`,
`a_listen` из истории чата открывают хаб. Избранное, стоп-листы и предпочтения не
затронуты.
