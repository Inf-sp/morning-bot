# Администраторская инструкция

## Запуск

Локально:

```bash
python -m pip install -r requirements.txt
python bot.py
```

Railway запускает тот же `python bot.py`. Секреты и ключи передаются через
переменные окружения; не добавляй их в код, документацию или логи.

## Пользовательские команды

- `/menu` — главное меню;
- `/settings` — общие настройки;
- `/admin` — админка для владельца.

## AI и внешние сервисы

Маршрутизация AI, лимиты, cooldown, кэш и резервные провайдеры находятся в
`ai.py` и `provider_runtime.py`. Модули функций не выбирают провайдера сами.
Для каждого текстового и structured AI-запроса общий слой сохраняет часть
дедлайна следующему разрешённому провайдеру: ошибка, тайм-аут, пустой или
невалидный ответ основной модели сразу передаются резерву. Ограничения
приватности продолжают определять, каким резервам можно передавать конкретные
данные.
Статус следующего запроса и оставшиеся квоты показываются в админском экране
`🛠 Система`; пользовательские экраны не показывают raw ошибки и имена
провайдеров.

Для постеров и трейлеров игровых премьер создай серверное приложение в Twitch Developer
Console и добавь в окружение Railway `IGDB_CLIENT_ID` и `IGDB_CLIENT_SECRET`. Без них
премьеры игр остаются доступными, но приходят без галереи; повторный деплой кода не нужен
после добавления переменных.

## Данные и безопасность

Пользовательский экспорт доступен через `🎚️ Настройки → 📤 Экспорт данных`.
Удаление элементов из личных списков всегда подтверждается.

## Проверка изменений

Перед деплоем запускай подходящие тесты и минимум:

```bash
python -m compileall -q .
python verify.py
```

После изменения callback-ов дополнительно запускай `python routing.py`. Номер
версии при необходимости меняется напрямую в файле `VERSION`.
# Язык внешнего поиска

Автоматические рекомендации ищут актуальные сведения английскими запросами.
Пользователь получает описания, факты и пояснения на русском; оригинальными остаются
имена людей, названия произведений, заведений, площадок и брендов. Если перевод
внешнего описания недоступен, бот скрывает его вместо показа английского текста.
