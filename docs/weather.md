# Погода

## Назначение
Раздел "Погода" показывает прогноз для города пользователя — на сегодня, на завтра, подробный почасовой прогноз и прогноз на ближайшую неделю. Помогает быстро понять, что надевать и чего ожидать от дня, без необходимости открывать сторонние приложения.

## Как это работает
Погодные данные бот берёт из OpenWeatherMap One Call API 4.0 по ключу `WEATHER_API_KEY`. Ключ создаётся в кабинете OpenWeatherMap: https://home.openweathermap.org/api_keys, а на One Call API 4.0 должна быть отдельно активирована подписка на https://home.openweathermap.org/subscriptions — без неё запросы будут отклоняться с ошибкой авторизации. Утром бот заранее прогревает прогноз перед "Мой день", а успешный ответ сохраняет в устойчивый кэш на 3 часа: повторные разделы вроде погодного предупреждения или гардероба читают эти же данные без новых запросов, а прогноз при этом чаще обновляется свежими данными. Если OpenWeather временно недоступен (сбой, лимит, нет ключа), бот берёт сегодняшний закэшированный прогноз, а без него — резерв без ключа Open-Meteo (`weather_provider._fetch_open_meteo`, тот же формат: WMO-коды, м/с, время Амстердама; без погодных алертов), и кэширует его как обычный ответ. После сбоя OpenWeather полчаса не запрашивается (`_OWM_PAUSE_SECONDS`): погода сразу берётся из Open-Meteo, без ожидания таймаутов; у Open-Meteo своё время ответа — не меньше 5 с, даже если OpenWeather съел бюджет действия.
При явном открытии «Моего дня» текущие условия уточняются отдельно и кэшируются
на 10 минут; дневной и почасовой прогноз повторно не запрашиваются.

One Call API 4.0 разбит на несколько отдельных запросов (текущая погода, почасовой прогноз, дневной прогноз), которые бот делает параллельно, чтобы не терять скорость ответа. Погодные предупреждения (алерты) в этой версии API сначала приходят как краткий идентификатор, и только если алерт действительно есть — бот делает один дополнительный запрос за его деталями.

В зависимости от того, что выбрал пользователь, бот показывает разные форматы:

- **Погода на сегодня** — заголовок с датой и городом, основная строка с температурой, дождём (если он есть и вероятность высокая) и ветром. Дополнительно бот подмешивает шутливый факт о погоде в одном из городов мира прямо сейчас (например, "кстати, сегодня в Дубае +45°C").
- **Погода на завтра** — похожий формат, но вместо шутки о мировой погоде бот показывает предупреждение об опасной погоде, если ожидается шторм, сильный ветер, снег или ливень.
- **Погода на завтра (упрощённый вариант)** — по сути то же самое, что "на завтра", но без метеофакта и без текстового итога: только утро, день и вечер.
- **Полный прогноз на сегодня** — прогноз разбит на части дня (утро/день/вечер/ближайшая ночь), для каждой части — своя температура, вероятность дождя и ветер. В конце находится словесное ожидание погоды на завтра без температур, процентов и других чисел.
- **Прогноз на неделю** — жирный заголовок `Неделя · 27 ноя – 3 дек · Alkmaar, NL 🇳🇱`; под ним — тренд недели без AI (`weather_weekly.week_story`): «Теплеет: с +1° до +8° к среде.» / «Холодает: …» (разница начала и конца недели от 3°) или «Ровно: от +4° до +6°», плюс итог, если он есть: «Без дождя всю неделю.» / «Дождь почти каждый день.»; затем семь строк с максимальной температурой дня (`0°`, не `-0°`) и пометкой только когда есть что сказать (`weather_weekly.day_note`): «Вс · 🌧️ +4° · дождь 80%», «Ср · ☁️ +8° · ветер 12 м/с» (от 10 м/с); внизу вместо общей фразы «На следующей неделе…» — «Лучший день — пятница: солнечно, без дождя, +1°.» (сухо → солнце → без сильного ветра → теплее) и «Выходные: сб сухо, вс дождь.». Температуры, ветер, осадки и облачность рассчитываются по окну 08:00–20:00 (`weather.day_conditions`), если почасовой прогноз покрывает всё окно; для дальних дней — суточный прогноз провайдера целиком, источники в одном дне не смешиваются. Ночные минимумы и ночная погода не показываются: дождь только ночью не делает день дождливым. Значок дня: 🌧️ / 🌩️ — только при реальных осадках (≥ 50% и ≥ 0,1 мм), иначе 🌫️ при тумане или небо по облачности ☀️ / 🌤️ / ☁️. ❄️ — только снег или мороз (`weather._snow_icon`, так же в «Моём дне»): осадки при снежном коде дня и максимуме не выше +3° (теплее днём — это дождь, снег был ночью) или осадки не выше +1°, либо весь день не теплее 0°; в плюс без снега снежинки нет. «Снег» в описании недели — только при реальных осадках. Совет «Завтра …» в полном прогнозе считается так же.  Дни не объединяются, длинные описания и отдельный «Метео-итог» не используются. Окно 08:00–20:00 у недели — по местному времени и на все 7 дней: дневные показатели берутся из почасового Open-Meteo в часовом поясе места (`weather_provider.week_hourly`, в отпуске — пояс поездки, кэш час): у основного провайдера часы есть только на ~48 ч, а дальше суточный итог включает ночь — ночная гроза давала 🌧️ на сухой день. Open-Meteo не ответил — прежняя логика.

Недельный экран целиком строится по данным OpenWeatherMap. Краткое описание и
совет выбираются локальными правилами по температуре, осадкам и ветру, поэтому
бот не придумывает погодные условия и не вызывает AI для этого прогноза.

Отдельно есть ежедневное **погодное предупреждение** (по умолчанию в 08:00; варианты 07:00 / 08:00 / 09:00). Оно приходит только в дни, когда ожидается хотя бы один значимый фактор: гроза, гололёд, штормовой ветер, сильный дождь, жара, высокий UV, снег, мороз, туман или высокая влажность. Спокойные дни не присылаются. Предупреждение включено по умолчанию и отключается в `🎚️ Настройки` → `🔔 Уведомления`. Под предупреждением — `🎚️ Настроить уведомления | #️⃣ Главная` (экран уведомлений открывается новым сообщением, предупреждение остаётся в истории); красной «Отключить уведомления» нет.

Уведомление с прогнозом на завтра (по умолчанию в 20:00; варианты 18:00 / 20:00 / 21:00) в стиле остальных уведомлений: заголовок
`🌧️ Погода на завтра · сб, 18 июля` (значок — погода дня), ниже «**Город:** Alkmaar, NL 🇳🇱» (код страны и флаг — как в
«Полном прогнозе»). Ниже прогноз развёрнут по частям суток — блоком на утро (08–12),
день (12–18) и вечер (18–24), из тех же почасовых данных, что и «Полный прогноз» (`weather.forecast_periods(...,
day=1)`, `weather._period_lines`); часы — почасовой Open-Meteo во времени места (`weather_provider.week_hourly`, в
отпуске — пояс поездки), поэтому вечер завтра есть всегда: у основного провайдера часы только на ~48 ч от запроса. У блока — жирная подпись со значком, ниже строки «**Подпись:** значение», как во всех уведомлениях;
между блоками — пустая строка:

```
🌧️ Погода на завтра · сб, 17 октября

**Город:** Alkmaar, NL 🇳🇱

**☀️ Утром:**
**Температура:** до +14°C
**Осадки:** без дождя
**Ветер:** 4 м/с

**🌧️ Днём:**
**Температура:** до +18°C
**Осадки:** 🌧️ дождь 70%
**Ветер:** 11 м/с, сильный

**☁️ Вечером:**
**Температура:** до +15°C
**Осадки:** без дождя
**Ветер:** 4 м/с
```

Значок — по небу и дождю этой части суток; процент дождя — только если дождь реален, со значком: «**Осадки:** 🌧️ дождь 70%», иначе «без дождя»; ❄️ — только если пойдёт снег (реальные осадки при снежном коде дня и не выше +3° или осадки не выше +1°, `weather.snowfall`) или вся часть суток в минусе (максимум не выше 0°, `weather.snowflake`); в плюс без снега — обычный знак погоды («☁️ Утром» при +1°…+2°; `weather.period_title`), а при минусе с дождём у температуры ещё «до +1°C · гололёд» (`weather._period_lines`, поле `tmin`); ветер —
диапазон за часы части суток, выше 10 м/с — «11 м/с, сильный». Без почасовых данных — одна общая строка,
как в «Моём дне»: `🌧️ Погода: дождь днём и вечером, до +20° · ветер до 9 м/с`. Метео-итога нет; ниже —
только предупреждение об опасной погоде, если она ожидается. Под сообщением в один столбец:
`🎚️ Настроить` — настройки уведомлений новым сообщением, в самом низу `#️⃣ Главная`; прогноз
остаётся в истории. Кнопок «Погода на неделю» и «Отключить уведомления» под этой рассылкой нет (подпись — `🎚️ Настроить уведомления`).

Формат предупреждения всегда компактный, эмодзи — только в заголовке:

```
❄️ Погодное предупреждение                 ← без страны

**Город:** Alkmaar                         ← подпись до двоеточия жирным, как во всех уведомлениях
**Причина:** Возможен гололёд.             ← одно событие; 2–3 — «**Причины:**» и пункты «• …»
**Когда:** в течение дня                   ← жирная подпись, без курсива
```

В отпуске время «Когда» — местное: часы прогноза (время Амстердама) сдвигаются на разницу поясов места поездки
(`weather_warn._local_when`, `vacation.local_tz`).

Значок заголовка — главного (самого важного) события: ⛈️ гроза, ❄️ гололёд, 💨 штормовой ветер,
🌧️ дождь, 🌡️ жара, ☀️ UV, ❄️ снег, ❄️ мороз (мороз, минус, снег и лёд — везде ❄️), 🌫️ туман, 💧 влажность. Если сработало несколько
факторов, бот объединяет их в одно сообщение и выбирает до трёх самых важных событий. Блока
«Что сделать» с рекомендациями нет.
Для дождя блок «Когда» показывает отдельные непрерывные периоды и вероятность в каждом из них, например `08:00–10:00 · дождь 60–75%`, а не один общий диапазон дня.

При смене города (текстом, через геолокацию или подтверждением при первой настройке) бот заново определяет координаты через OpenWeatherMap Geocoding API по тому же `WEATHER_API_KEY`; при неудаче использует запасной Nominatim (OpenStreetMap). Бот также старается распознать неофициальные названия городов ("Питер" → "Санкт-Петербург") и подобрать правильное русское написание, сверяясь через модель ИИ. Подтверждение смены города показывает флаг определённой страны. После успешной смены города бот сразу обновляет и присылает актуальную сводку "Мой день".

При отправке геолокации (через кнопку "поделиться местоположением" в Telegram) город определяется автоматически по координатам через отдельный сервис обратного геокодирования, после чего сразу показывается погода на сегодня.

## Основные возможности
- Прогноз на сегодня, на завтра, подробный прогноз на сегодня и на неделю вперёд. После заголовка и пустой строки показывается единая строка `Восход … → Закат …` без эмодзи. Полный прогноз показывает текущий дневной период по оставшимся часам, следующие дневные периоды и ближайшую ночь следующего календарного дня: в 10:00 — утро (10–12), день и вечер; в 15:00 — день (15–18) и вечер. Эмодзи периода — по его часам: 🌧️ / 🌩️ / ❄️ только при реальном дожде в периоде, иначе по средней облачности `☀️` (< 30%), `🌤️` (< 70%), `☁️`; вечером и ночью — знак погоды без солнца и без луны: ясно — `✨`, переменная облачность — `☁️`, ветер и осадки — как есть (`weather.evening_icon`). Так же вечером значок строки погоды «Моего дня» (и образа дня в отпуске, он берёт ту же погоду). Восход и закат показываются по местному времени города. Часть суток — одной строкой: `❄️ **Утром:** -1° · ветер 5–6 м/с` (заголовок «Полный прогноз · Чт, 26 ноября · Alkmaar, NL 🇳🇱», восход — `Восход 08:21 → закат 16:34`); временные интервалы пользователю не показываются; температура — максимум части суток, около нуля — `0°`, а не `-0°` (`weather.degrees`); ❄️ — только если пойдёт снег (реальные осадки при снежном коде дня и не выше +3° или осадки не выше +1°, `weather.snowfall`) или вся часть суток в минусе (максимум не выше 0°, `weather.snowflake`); в плюс без снега — обычный знак погоды (`❄️ Ночью`), при минусе с дождём ещё `· гололёд`; дождь — только реальный: `· 🌧️ дождь 70%`, без дождя весь день — «Без дождя.» в начале строки совета. Было 22 строки на 4 части суток — стало 9. Порывы ветра и облачность не выводятся; дождь остаётся отдельной короткой строкой. Объём осадков отдельной строкой не выводится. Отдельного блока «Сейчас» нет. Вечерний золотой час (солнце от −4° до +6°) — последним предложением строки совета (без подписи «Полезно:») (`… Золотой час будет с 18:18 по 19:25.`), без эмодзи; утренний и синий час не показываются; расчёт по координатам города по формулам NOAA (`sun.py`), без внешних API. В отпуске восход, закат и золотой час показываются во времени места поездки (`vacation.local_tz`: часовой пояс по координатам из Open-Meteo `timezone=auto`, кэш 30 дней; в обработчике без сети), а не Амстердама — иначе после перевода часов в Европе время сдвигалось на час. Под результатом находится широкая кнопка `🗓️ Погода на неделю`, затем `⬅️ Назад | #️⃣ Главная`.
- Показ температуры, вероятности и силы дождя, силы и направления ветра.
- Предупреждения об опасной погоде: сильный ветер (шквалы), снегопад, ливень или гроза — с более развёрнутыми предупреждениями для Нидерландов (упоминание задержек поездов NS, ссылка на Buienradar).
- Ежедневное погодное предупреждение по расписанию, только если есть значимый погодный риск.
- Пояснение о комфорте с учётом влажности воздуха (например, что жара из-за влажности ощущается сильнее, чем показывает термометр).
- Интересные факты: шутливое сравнение с погодой в другом городе мира.
- Смена города текстом (с распознаванием неофициальных названий) или через геолокацию.
- Кнопки быстрого перехода между разделами (назад к сводке дня, к недельному прогнозу).

## Настройки
- **Город и координаты** — главная настройка, от неё зависит вообще весь прогноз; меняется через ввод названия города или отправку геолокации.
- **Погодное предупреждение** — включено по умолчанию, приходит при действительно важной погоде и отдельно отключается в настройках уведомлений.
- **Предупреждение на завтра** — тот же переключатель, вечером в 19:00 (`bot.job_weather_warn_tomorrow`,
  `settings.send_weather_warn_tomorrow`, `weather_warn.build_warning(..., tomorrow=True)`): прогноз на завтра
  (`weather_warn.tomorrow_view` — дневные ряды со второго дня) и только то, к чему готовятся заранее
  (`TOMORROW_KEYS`: гроза, гололёд, шторм, сильный дождь, снег, жара, мороз; UV, туман и влажность — нет).
  Заголовок «💨 Погодное предупреждение на завтра», внизу «**Когда:** 12:00–18:00»; дождь —
  «Ожидается дождь…» без «Сегодня». Спокойно — ничего не приходит.
- Явных пользовательских настроек (включить/выключить какие-то блоки погоды, изменить единицы измерения и т.п.) в разделе не предусмотрено — прогноз показывается в едином формате для всех.

## Ограничения
- Дождь в сводке упоминается (эмодзи, проценты, фраза "дождь") только если вероятность осадков составляет не менее 50%; более низкая вероятность считается несущественной и не показывается вовсе.
- Во всех погодных экранах вероятность и объём осадков, температура и ветер уточняются по почасовому окну 08:00–20:00, чтобы ночные условия не влияли на решение на день.
- Текущий код OpenWeather имеет приоритет для осадков: если дождь уже начался,
  «Мой день» пишет «Дождь сейчас» без выдуманного процента.
- Даже при высокой вероятности дождь может быть проигнорирован, если ожидаемое количество осадков в миллиметрах ничтожно мало (меньше десятой доли миллиметра) — вероятность может быть "статистическим шумом".
- Предупреждение о ветре с усиленной формулировкой ("сильный ветер"/"очень сильный ветер") появляется только начиная с определённой силы ветра; более слабый ветер описывается нейтрально.
- Штормовое предупреждение (шквалы, ливень, снег) показывается только при действительно серьёзных значениях: ветер выше особого порога (около 15 м/с), сильные коды осадков (ливень, гроза) или выпадение от 15 мм осадков за день и больше.
- Расширенные предупреждения про поезда NS и сервис Buienradar показываются только для Нидерландов; для других стран — общие формулировки про задержки транспорта.
- Пояснение про влажность воздуха показывается не всегда, а только при определённых сочетаниях влажности и температуры (например, высокая влажность вместе с достаточно высокой температурой, либо очень низкая влажность).
- Кеш погодных данных живёт 3 часа и один на точку (`weather_provider._weather_cache_key` — без числа дней): «Мой день», Гардероб, «Полный прогноз на сегодня» и «Погода на неделю» читают один и тот же ответ API. Если свежий запрос не прошёл, бот может fallback'нуться на сегодняшний кэш до 24 часов, но не подставляет вчерашний прогноз как сегодняшний.
- Если API погоды не ответил и кэша нет, «Полный прогноз» и «Погода на неделю» показывают «🌦️ Прогноз сейчас недоступен — сервис погоды не ответил.» с курсивной подсказкой «Попробуй через несколько минут.» и `⬅️ Назад | #️⃣ Главная`, а причина пишется в лог (`send_weather: forecast unavailable`), без общего «Что-то пошло не так».
- Дневной лимит запросов к OpenWeatherMap выставлен на уровне 1000 запросов/день (в кабинете OpenWeather) — это реальный бесплатный потолок One Call API 4.0, а не искусственно заниженное значение.
- Если город не удаётся найти ни через один из геосервисов, бот сообщает, что не нашёл город, и просит попробовать снова.
- Погодное предупреждение не учитывает AQI и пыльцу: для этого нужен отдельный источник данных. Переключатель аллергии заведён на будущее, но без данных о пыльце фактор честно не срабатывает.
- Интервал «Когда» в погодном предупреждении строится по дневному окну; ночные явления могут не попасть в утреннее сообщение.

## Официальные предупреждения KNMI

Дома в Нидерландах погодное предупреждение сверяется с официальными предупреждениями KNMI через MeteoAlarm
(`meteoalarm.py`, `feeds.meteoalarm.org`, CAP в JSON, без ключа, кэш 15 минут): предупреждение берётся, только если
координаты из Настроек внутри полигона его зоны. Уровень и вид — из параметров CAP по-русски без AI: «🟡 жёлтый /
🟠 оранжевый / 🔴 красный», «ветер, снег и гололёд, гроза, туман, жара, мороз, сильный дождь…». Официальное
предупреждение — первым пунктом и значком заголовка: «**Причина:** Код оранжевый KNMI — ветер, с 14:00 до 21:00.»;
дальше — свой расчёт по прогнозу. Если свой расчёт молчит, а KNMI предупреждает, — уведомление всё равно приходит.
Накануне в 19:00 — предупреждения, которые действуют завтра. MeteoAlarm не ответил — только свой расчёт.
