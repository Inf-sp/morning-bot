# Погода

## Назначение
Раздел "Погода" показывает прогноз для города пользователя — на сегодня, на завтра, подробный почасовой прогноз и прогноз на ближайшую неделю. Помогает быстро понять, что надевать и чего ожидать от дня, без необходимости открывать сторонние приложения.

## Как это работает
Погодные данные бот берёт из OpenWeatherMap One Call API 4.0 по ключу `WEATHER_API_KEY`. Ключ создаётся в кабинете OpenWeatherMap: https://home.openweathermap.org/api_keys, а на One Call API 4.0 должна быть отдельно активирована подписка на https://home.openweathermap.org/subscriptions — без неё запросы будут отклоняться с ошибкой авторизации. Утром бот заранее прогревает прогноз перед "Мой день", а успешный ответ сохраняет в устойчивый кэш на 3 часа: повторные разделы вроде погодного предупреждения или гардероба читают эти же данные без новых запросов, а прогноз при этом чаще обновляется свежими данными. Если OpenWeather временно недоступен (сбой, лимит, нет ключа), бот берёт сегодняшний закэшированный прогноз, а без него — резерв без ключа Open-Meteo (`weather_provider._fetch_open_meteo`, тот же формат: WMO-коды, м/с, время Амстердама; без погодных алертов), и кэширует его как обычный ответ. После сбоя OpenWeather полчаса не запрашивается (`_OWM_PAUSE_SECONDS`): погода сразу берётся из Open-Meteo, без ожидания таймаутов; у Open-Meteo своё время ответа — не меньше 5 с, даже если OpenWeather съел бюджет действия.
При явном открытии «Моего дня» текущие условия уточняются отдельно и кэшируются
на 10 минут; дневной и почасовой прогноз повторно не запрашиваются.

One Call API 4.0 разбит на несколько отдельных запросов (текущая погода, почасовой прогноз, дневной прогноз), которые бот делает параллельно, чтобы не терять скорость ответа. Погодные предупреждения (алерты) в этой версии API сначала приходят как краткий идентификатор, и только если алерт действительно есть — бот делает один дополнительный запрос за его деталями.

В зависимости от того, что выбрал пользователь, бот показывает разные форматы:

- **Погода на сегодня** — заголовок с датой и городом, основная строка с температурой, дождём (если он есть и вероятность высокая) и ветром. Дополнительно бот подмешивает шутливый факт о погоде в одном из городов мира прямо сейчас (например, "кстати, сегодня в Дубае +45°C").
- **Погода на завтра** — похожий формат, но вместо шутки о мировой погоде бот показывает предупреждение об опасной погоде, если ожидается шторм, сильный ветер, снег или ливень.
- **Погода на завтра (упрощённый вариант)** — по сути то же самое, что "на завтра", но вместо метеофакта показывается короткий текстовый итог-обзор погоды на 2-3 предложения (без слова "зонт" — специально избегается).
- **Полный прогноз на сегодня** — прогноз разбит на части дня (утро/день/вечер/ближайшая ночь), для каждой части — своя температура, вероятность дождя и ветер. В конце находится словесное ожидание погоды на завтра без температур, процентов и других чисел.
- **Прогноз на неделю** — жирный заголовок `Неделя с 5–11 авг · Лилль, FR 🇫🇷`, одна короткая текстовая характеристика недели без значка и температур с многоточием в конце (`Часто дождь, временами ветрено…`) и семь строк с максимальной температурой дня. Температуры, ветер, осадки и облачность рассчитываются по окну 08:00–20:00 (`weather.day_conditions`), если почасовой прогноз покрывает всё окно; для дальних дней — суточный прогноз провайдера целиком, источники в одном дне не смешиваются. Ночные минимумы и ночная погода не показываются: дождь только ночью не делает день дождливым. Значок дня: 🌧️ / 🌩️ / ❄️ — только при реальных осадках (≥ 50% и ≥ 0,1 мм), иначе 🌫️ при тумане или небо по облачности ☀️ / 🌤️ / ☁️. «Снег» в описании недели — только при реальных осадках. Совет «Завтра …» в полном прогнозе считается так же. В конце отдельной строкой, без подписи «Полезно:», словесное ожидание погоды на следующую неделю без температур, процентов и других чисел. Дни не объединяются, длинные описания и отдельный «Метео-итог» не используются.

Недельный экран целиком строится по данным OpenWeatherMap. Краткое описание и
совет выбираются локальными правилами по температуре, осадкам и ветру, поэтому
бот не придумывает погодные условия и не вызывает AI для этого прогноза.

Отдельно есть ежедневное **погодное предупреждение** (по умолчанию в 08:00; варианты 07:00 / 08:00 / 09:00). Оно приходит только в дни, когда ожидается хотя бы один значимый фактор: гроза, гололёд, штормовой ветер, сильный дождь, жара, высокий UV, снег, мороз, туман или высокая влажность. Спокойные дни не присылаются. Предупреждение включено по умолчанию и отдельно отключается в `🎚️ Настройки` → `🔔 Уведомления` или кнопкой под самим сообщением. Под предупреждением находятся широкие кнопки `🔕 Отключить уведомления` и `#️⃣ Главная`; переход сохраняет само предупреждение в истории.

Уведомление с прогнозом на завтра (по умолчанию в 20:00; варианты 18:00 / 20:00 / 21:00) начинается с компактного жирного заголовка
`Завтра · Сб, 18 июля · Алкмар 📍`. Следующая строка единообразна с «Моим днём»:
`🌧️ Погода: до +20°C · Дождь днём и вечером · Ветер до 9 м/с`. Проценты,
разговорные классификации силы и разделители `•` не показываются; при ветре выше
10 м/с используется подпись `Сильный ветер`. Под сообщением в один столбец:
`🎚️ Настроить` — настройки уведомлений новым сообщением, в самом низу `#️⃣ Главная`; прогноз
остаётся в истории. Кнопок «Погода на неделю» и «Отключить уведомления» под этой рассылкой нет.

Формат предупреждения всегда компактный, эмодзи — только в заголовке:

```
🌧️ Погодное предупреждение

<1-3 самых важных погодных события, без значков>

Когда:
<период дождя · вероятность, по одной строке для каждого окна>
```

Значок заголовка — главного (самого важного) события: ⛈️ гроза, 🧊 гололёд, 💨 штормовой ветер,
🌧️ дождь, 🌡️ жара, ☀️ UV, ❄️ снег, 🥶 мороз, 🌫️ туман, 💧 влажность. Если сработало несколько
факторов, бот объединяет их в одно сообщение и выбирает до трёх самых важных событий. Блока
«Что сделать» с рекомендациями нет.
Для дождя блок «Когда» показывает отдельные непрерывные периоды и вероятность в каждом из них, например `08:00–10:00 · дождь 60–75%`, а не один общий диапазон дня.

При смене города (текстом, через геолокацию или подтверждением при первой настройке) бот заново определяет координаты через OpenWeatherMap Geocoding API по тому же `WEATHER_API_KEY`; при неудаче использует запасной Nominatim (OpenStreetMap). Бот также старается распознать неофициальные названия городов ("Питер" → "Санкт-Петербург") и подобрать правильное русское написание, сверяясь через модель ИИ. Подтверждение смены города показывает флаг определённой страны. После успешной смены города бот сразу обновляет и присылает актуальную сводку "Мой день".

При отправке геолокации (через кнопку "поделиться местоположением" в Telegram) город определяется автоматически по координатам через отдельный сервис обратного геокодирования, после чего сразу показывается погода на сегодня.

## Основные возможности
- Прогноз на сегодня, на завтра, подробный прогноз на сегодня и на неделю вперёд. После заголовка и пустой строки показывается единая строка `Восход … → Закат …` без эмодзи. Полный прогноз показывает текущий дневной период по оставшимся часам, следующие дневные периоды и ближайшую ночь следующего календарного дня: в 10:00 — утро (10–12), день и вечер; в 15:00 — день (15–18) и вечер. Эмодзи периода — по его часам: 🌧️ / 🌩️ / ❄️ только при реальном дожде в периоде, иначе по средней облачности `☀️` (< 30%), `🌤️` (< 70%), `☁️`; ночью ясно — `🌙`. Восход и закат показываются по местному времени города. Заголовки периодов содержат только погоду и название: `Утром`, `Днём`, `Вечером`, `Ночью`; временные интервалы пользователю не показываются. Температура выводится отдельным пунктом `Температура до +20°C`. Порывы ветра и облачность не выводятся; дождь остаётся отдельной короткой строкой. Объём осадков отдельной строкой не выводится. Отдельного блока «Сейчас» нет. Вечерний золотой час (солнце от −4° до +6°) — последним предложением строки совета (без подписи «Полезно:») (`… Золотой час будет с 18:18 по 19:25.`), без эмодзи; утренний и синий час не показываются; расчёт по координатам города по формулам NOAA (`sun.py`), без внешних API. Под результатом находится широкая кнопка `🗓️ Погода на неделю`, затем `⬅️ Назад | #️⃣ Главная`.
- Показ температуры, вероятности и силы дождя, силы и направления ветра.
- Предупреждения об опасной погоде: сильный ветер (шквалы), снегопад, ливень или гроза — с более развёрнутыми предупреждениями для Нидерландов (упоминание задержек поездов NS, ссылка на Buienradar).
- Ежедневное погодное предупреждение по расписанию, только если есть значимый погодный риск.
- Пояснение о комфорте с учётом влажности воздуха (например, что жара из-за влажности ощущается сильнее, чем показывает термометр).
- Интересные факты: шутливое сравнение с погодой в другом городе мира.
- Смена города текстом (с распознаванием неофициальных названий) или через геолокацию.
- Кнопки быстрого перехода между разделами (назад к сводке дня, к недельному прогнозу).

## Настройки
- **Город и координаты** — главная настройка, от неё зависит вообще весь прогноз; меняется через ввод названия города или отправку геолокации.
- **Погодное предупреждение** — включено по умолчанию, приходит при действительно важной погоде и отдельно отключается в настройках уведомлений.
- Явных пользовательских настроек (включить/выключить какие-то блоки погоды, изменить единицы измерения и т.п.) в разделе не предусмотрено — прогноз показывается в едином формате для всех.

## Ограничения
- Дождь в сводке упоминается (эмодзи, проценты, фраза "дождь") только если вероятность осадков составляет не менее 50%; более низкая вероятность считается несущественной и не показывается вовсе.
- Во всех погодных экранах вероятность и объём осадков, температура и ветер уточняются по почасовому окну 08:00–20:00, чтобы ночные условия не влияли на решение на день.
- Текущий код OpenWeather имеет приоритет для осадков: если дождь уже начался,
  «Мой день» пишет «Дождь сейчас» без выдуманного процента.
- Даже при высокой вероятности дождь может быть проигнорирован, если ожидаемое количество осадков в миллиметрах ничтожно мало (меньше десятой доли миллиметра) — вероятность может быть "статистическим шумом".
- Предупреждение о ветре с усиленной формулировкой ("сильный ветер"/"очень сильный ветер") появляется только начиная с определённой силы ветра; более слабый ветер описывается нейтрально.
- Штормовое предупреждение (шквалы, ливень, снег) показывается только при действительно серьёзных значениях: ветер выше особого порога (около 15 м/с), сильные коды осадков (ливень, гроза) или выпадение от 15 мм осадков за день и больше.
- Расширенные предупреждения про поезда NS и сервис Buienradar показываются только для Нидерландов; для других стран — общие формулировки про задержки транспорта.
- Пояснение про влажность воздуха показывается не всегда, а только при определённых сочетаниях влажности и температуры (например, высокая влажность вместе с достаточно высокой температурой, либо очень низкая влажность).
- Кеш погодных данных живёт 3 часа и один на точку (`weather_provider._weather_cache_key` — без числа дней): «Мой день», Гардероб, «Полный прогноз на сегодня» и «Погода на неделю» читают один и тот же ответ API. Если свежий запрос не прошёл, бот может fallback'нуться на сегодняшний кэш до 24 часов, но не подставляет вчерашний прогноз как сегодняшний.
- Если API погоды не ответил и кэша нет, «Полный прогноз» и «Погода на неделю» показывают «🌦️ Прогноз сейчас недоступен — сервис погоды не ответил.» с курсивной подсказкой «Попробуй через несколько минут.» и `⬅️ Назад | #️⃣ Главная`, а причина пишется в лог (`send_weather: forecast unavailable`), без общего «Что-то пошло не так».
- Дневной лимит запросов к OpenWeatherMap выставлен на уровне 1000 запросов/день (в кабинете OpenWeather) — это реальный бесплатный потолок One Call API 4.0, а не искусственно заниженное значение.
- Если город не удаётся найти ни через один из геосервисов, бот сообщает, что не нашёл город, и просит попробовать снова.
- Погодное предупреждение не учитывает AQI и пыльцу: для этого нужен отдельный источник данных. Переключатель аллергии заведён на будущее, но без данных о пыльце фактор честно не срабатывает.
- Интервал «Когда» в погодном предупреждении строится по дневному окну; ночные явления могут не попасть в утреннее сообщение.
