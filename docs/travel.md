# ✈️ Поездки

## Назначение
Раздел показывает «Место дня» и помогает выбрать путешествие по части света.

## Как это работает
Главный экран показывает `Место дня` в своей или соседней стране: жирный заголовок с названием, выделенное место с короткой особенностью, отдельный блок `Что интересного:` (до 3 пунктов списком) и совет `💡 Полезно`. Блоки разделены пустыми строками, заголовки жирные. Туристического ребуса нет. Идея кэшируется на неделю, пересобирается после смены города или страны и имеет безопасный локальный резерв.

«✨ Подобрать новое путешествие» не зависит от доступности AI: при сбое выбирается новая страна из локального каталога, а карточка собирается из готового редакторского профиля. Локальный запас покрывает все 20 направлений резервного пула и для каждого хранит описание, характер поездки, три места, сезон, бюджет, языки, LGBTQ+-оценку и ссылки на источники. AI только усиливает персонализацию и не нужен для полноты карточки. Во время поиска текущая карточка остаётся на месте, меняется только её inline-клавиатура со статусом, а готовая новая карточка приходит отдельным сообщением.

Кнопка «🎚️ Мой чемодан» открывает список посещённых стран; `✅ Добавить страну` стоит сразу над навигацией. Страны хранятся по стабильным ISO-кодам; технические идентификаторы, HEX-значения и записи без настоящего названия пользователю не показываются. Страны сортируются по названию, показываются по две в ряд и по десять на странице. Номер страницы находится только в кнопках пагинации.

Пагинация использует кнопки `◀️` и `▶️` и переключает страницы по кругу: после последней открывается первая, а перед первой — последняя.

«✨ Подобрать новое путешествие» сразу показывает короткую редакторскую карточку с одной горизонтальной туристической фотографией: характер поездки, одно конкретное совпадение со вкусами, три разноплановых места, сезон с причиной, бюджет с причиной, полезные языки и практичная LGBTQ+-оценка. Для персонализации выбираются только один-два сильных интереса. Блок случайного факта не показывается. Промежуточного превью и кнопки «Показать подробности» нет. Бот ищет природный пейзаж, архитектуру или узнаваемое место через Pexels, отбрасывает портреты, людей, еду, карты, флаги и текстовые изображения, затем выбирает один лучший результат. Фото хранится вместе с карточкой; имя автора и источник не показываются. После inline-ожидания новая карточка также приходит фотографией с подписью, а не упрощается до текста. Если Pexels недоступен, используется Unsplash; если фото получить не удалось или Telegram не принял URL, карточка остаётся рабочей в текстовом виде.

Флаг рекомендации определяется по ISO-коду страны через справочник, а не берётся как произвольный эмодзи из AI-ответа. Поэтому декоративные символы вроде `🌟` перед названием не показываются.

Посещённые страны из «Моего чемодана» запрещены для новых рекомендаций. Проверка выполняется по ISO-коду после генерации, поэтому другое написание или язык названия не обходят запрет. Если модель всё же вернула посещённую страну, её название добавляется в следующую попытку: prompt меняется и не получает прежний ответ из AI-кэша. Отдельного действия для сохранения готового плана нет.

Столица, валюты, языки, регион, ISO-код, координаты и флаг берутся из локального справочника по ISO-коду страны. Обычное открытие известной страны не делает внешний запрос. Если редкой записи в локальном справочнике не хватает, бот может разово обратиться к `countries.dev`; сбой этого резерва не ломает карточку. Готовые практические профили хранятся отдельно в `data/travel_country_profiles.json` и передаются модели как проверенные данные. LGBTQ+-оценка никогда не берётся из модели: при отсутствии свежего проверенного профиля карточка честно сообщает об ограничении. Бюджет оценивается словами «низкий», «средний» или «высокий» с одной главной причиной стоимости; произвольные числовые суммы не генерируются.

Tavily не используется для обычной карточки страны, достопримечательностей и базовой рекомендации. Он разрешён только в отдельном сценарии текущей информации, например для официальных визовых, транспортных или паромных правил, когда URL источника ещё неизвестен.

При первом открытии конкретной страны бот собирает компактную карточку и кэширует её по коду страны. Пока карточка собирается, список посещённых стран остаётся на месте и показывает кнопку «🗺️ Открываю страну...». Следующие открытия этой страны у любого пользователя читают готовую карточку из базы без AI-запроса. Удаление убирает только страну из личного списка и не удаляет общую карточку.

Если AI несколько раз предлагает уже посещённую или скрытую страну, бот без ошибки берёт другое направление из расширенного локального списка. Проверка повторов в нём также идёт по ISO-коду, поэтому другое написание страны не обходит запрет. Сообщение «Не удалось подобрать…» показывается только если свободных стран не осталось и там.

## Новые экраны

Главный экран показывает компактное `Место дня`: конкретное место, короткое описание,
что интересного (маршрут или идеи) и полезный совет для поездки. Туристического ребуса нет.

Кнопка `🧳 Другая страна` находится на главном экране Поездок и сразу подбирает новую страну по любому направлению. На экране подобранной страны доступна кнопка `🧭 По направлению` для выбора конкретного региона (Европа, Азия и др.).

## Основные возможности
- Получить актуальную идею поездки из своего города
- Подобрать новую страну и сразу получить полную карточку
- Получить одну визуальную обложку рекомендованной страны
- Открыть посещённые страны с пагинацией и компактными карточками
- Добавить или удалить посещённую страну без потери общего справочного кэша

Карточка посещённой страны показывает описание, чем она запоминается, языки на русском, валюту, главный нюанс и один факт.

## Ограничения
- Свежая идея может быть точнее с AI, но резервная рекомендация и полноценные карточки 20 локальных направлений доступны без него
- Для официального резерва фотографий требуется `UNSPLASH_ACCESS_KEY`; без него ошибка Pexels оставляет текстовую карточку
- Для редкого названия вне локального справочника код и недостающие поля могут уточняться через необязательный резерв
- Числовой бюджет не показывается без дат, длительности поездки и маршрута

Посещённые, отклонённые и недавно предложенные страны входят в общие исключения.
Локальный резерв продолжает подбор без ошибки и без текущего повтора.
