# Живой язык

## Назначение
«Живой язык» каждый день показывает одну естественную разговорную фразу на активном языке обучения. Блок помогает запоминать короткие выражения вместе с живым переводом и ситуацией употребления.

## Как это работает
Фраза — главный блок экрана «Обучение». Она выбирается из проверенного локального набора один раз на календарный день, поэтому не требует AI, не задерживает открытие карточки и не меняется при повторном входе.

Экран начинается с грамматики (фраза дня — в «Моём дне», строка `💬 Фраза дня`):

```text
🇳🇱 Изучаем сегодня · Нидерландский

Wachten op — ждать кого-то или чего-то.        ← жирным
В нидерландском глагол wachten обычно используется с предлогом op.

Как использовать:                              ← жирным
• Ждать человека — wachten op: Ik wacht op Sanne.
• Вместо «это» — erop: Ik wacht erop.

Пример: Ik wacht al een week op een antwoord → Я уже неделю жду ответа.   ← «Пример:» жирным

Твой нидерландский · 120 слов · 14 изученных тем   ← курсивом
```

- База тем — `grammar_topics.json`: 321 тема на нидерландском и 314 на английском (A1–B2: грамматика, порядок слов,
  времена, союзы, предлоги, глаголы с предлогами, устойчивые конструкции). Поля: `level`, `topic`, `meaning`,
  `explain` (краткое объяснение без примера — запасное), `details` (2–4 пункта подробного объяснения: что это и когда,
  как строится, на чём легко ошибиться; короткие примеры с переводом, без примера карточки), `example`, `translation`.
- Одна тема в день (`live_language.grammar_of_day`): держится до завтра, на следующий день — следующая ещё не
  показанная, без повторов, пока не пройдены все темы уровня (тогда круг заново по этому уровню). Только темы
  уровня из настроек обучения: «Простой» — A1–A2, «Сложный» — B1–B2 (уровень хранится под названием языка —
  `store.get_level(cid, "нидерландский")`); сменили уровень — тема дня подбирается заново в тот же день.
  Прогресс — `grammar_progress` в профиле по языку.
- Порядок: тема жирным «Тема — значение.» (без слова «Грамматика»; значение-формула — только она: «Daar + предлог.»;
  короткое значение из правила — в заголовок: «Zodra — как только.»), суть одной строкой, жирное «Как использовать:»
  с 1–3 пунктами «ситуация — форма: пример», «Пример: фраза → перевод.» одной строкой; строки «Запомни» нет. Последней строкой курсивом — статистика
  `Твой нидерландский · N слов · M изученных тем` (слова словаря на этом языке и показанные темы из
  `grammar_progress`; `learning._learning_stats`, `ui/menu.learning_stats_line`); в отпуске её нет. В отпуске
  вместо грамматики — экран «Обучение в отпуске · Африкаанс» с ситуацией дня — фразами строка к строке (`docs/settings.md`, «✈️ В отпуске»).
- Карточка темы (`live_language.build_lesson_card`): суть и «Как использовать» один раз на тему собирает ИИ
  (`cheap`, модуль `learning`, структурный ответ) только из разбора темы (`explain`, `details`, пример) и хранит навсегда
  в `grammar_cards.json` (`config.GRAMMAR_CARDS_KEY`), общей для всех пользователей. Ответ без русского объяснения или
  с примером не на изучаемом языке отбрасывается. Ночной прогрев «Обучения» готовит карточки темы дня и двух
  следующих («Новая тема»); если карточки ещё нет, экран не ждёт ИИ: собирается из `explain` (первое предложение —
  суть, остальные — «Как использовать»), а карточка достраивается фоном к следующему открытию.
- Фраза дня для строки `💬 Фраза дня` в «Моём дне» — отдельный запас `data/daily_phrases.json` (300+ разговорных фраз на nl и en, `live_language.daily_phrase`: без повторов, пока не пройден весь запас; см. `docs/day.md`).
- Строки-совета нет.
- У «Живого языка» нет отдельной кнопки, карточки или действия «Ещё вариант».

## Основные возможности
- Одна разговорная фраза уровня B1 с грамматикой и ещё одним примером с переводом.
- Нидерландский и английский — по 10 фраз в наборе (`live_language.py`).
- Один и тот же вариант на весь календарный день.
- Мгновенный показ без AI и внешних сервисов.

## Настройки
Язык фразы совпадает с активным языком обучения и меняется через `🎚️ Настройки` → `📝 Выбрать предпочтения` → `🧠 Обучение`.

## Ограничения
- В день показывается только одна фраза.
- Фразы выбираются из закреплённого набора и со временем повторяются.
- Набор один для уровней «Простой» и «Сложный» — рассчитан на B1.
- Отдельной истории показанных выражений нет.
