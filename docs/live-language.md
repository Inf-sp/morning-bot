# Живой язык

## Назначение
«Живой язык» каждый день показывает одну естественную разговорную фразу на активном языке обучения. Блок помогает запоминать короткие выражения вместе с живым переводом и ситуацией употребления.

## Как это работает
Фраза — главный блок экрана «Обучение». Она выбирается из проверенного локального набора один раз на календарный день, поэтому не требует AI, не задерживает открытие карточки и не меняется при повторном входе.

Экран — три строки с жирными подписями: фраза дня → грамматика из неё → ещё пример с этой грамматикой.

```text
Фраза дня: Geen probleem → Без проблем.

Грамматика: Zodra — как только. В придаточном предложении глагол стоит в конце: zodra ik thuis ben.

Ещё пример: Ik bel je terug zodra ik klaar ben → Я перезвоню тебе, как только закончу.
```

- Перевод везде через «→»; у фразы и примера точка в конце исходника снимается, у перевода ставится.
- Грамматика в формате «слово — значение. правило: короткий пример»; слова на изучаемом языке выделены курсивом.
- «Ещё пример» — новое предложение с той же грамматикой и переводом (поля `more`, `more_translation`).
- Строки-совета нет.
- У «Живого языка» нет отдельной кнопки, карточки или действия «Ещё вариант».

## Основные возможности
- Одна разговорная фраза уровня B1 с грамматикой и ещё одним примером с переводом.
- Нидерландский и английский — по 10 фраз в наборе (`live_language.py`).
- Один и тот же вариант на весь календарный день.
- Мгновенный показ без AI и внешних сервисов.

## Настройки
Язык фразы совпадает с активным языком обучения и меняется через `🎚️ Настройки` → `📝 Выбрать предпочтения` → `🧠 Обучение`.

## Ограничения
- В день показывается только одна фраза.
- Фразы выбираются из закреплённого набора и со временем повторяются.
- Набор один для уровней «Простой» и «Сложный» — рассчитан на B1.
- Отдельной истории показанных выражений нет.
