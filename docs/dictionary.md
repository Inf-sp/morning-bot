# Мой словарь

## Назначение

`🎚️ Мой словарь` — личная коллекция отдельных слов на нидерландском и
английском. Слова используются в тренажёре и в ежедневном материале.

Фразы, предложения, устойчивые выражения и многословные конструкции в словарь
не добавляются. Разговорные фразы остаются отдельным материалом `Живого языка`.

## Главные экраны

Обзор показывает количество слов для каждого языка:

```text
🇳🇱 Нидерландский (12)
🇬🇧 Английский (8)
⬅️ Назад | #️⃣ Главная
```

После выбора языка видны только непустые части речи. Поддерживаются:

- Прилагательные
- Глаголы
- Существительные
- Местоимения
- Наречия
- Предлоги
- Числительные
- Союзы
- Частицы
- Междометия

На экране языка находятся категории и `🆕 Добавить слово`, но нет кнопки списка.
Внутри открытой категории добавления нет: там находится `🔢 Показать списком`.
Список показывает слова этой категории кнопками в два столбца; нажатие сразу открывает
нужную полную карточку.

Существующие callback-и основных категорий сохраняют прежние индексы. Старый
callback категории `Предложения` совместимо возвращает на экран языка.

Внизу находятся:

```text
✨ Подобрать новые слова
🆕 Добавить слово
⬅️ Назад | #️⃣ Главная
```

## Добавление одного слова

Слово можно отправить после кнопки `🆕 Добавить слово` или обычной командой в
чате, например:

```text
добавь в словарь afspraak
Add мозг
```

Русское слово переводится на активный язык обучения. Иностранное слово
приводится к словарной форме: глагол — к инфинитиву, прилагательное — к базовой
форме. У нидерландского существительного `de/het` хранится отдельно и
показывается вместе с термином. Английское `to` допустимо во вводе глагола, но
не создаёт отдельную многословную запись.

Перед сохранением бот проверяет язык, перевод, часть речи, формы и короткие
примеры. При неоднозначности он просит выбрать значение. Дубликаты одного слова
внутри языка объединяются без потери переводов и прогресса.

## Если прислали фразу или предложение

Бот не сохраняет весь текст. Он выбирает одно частотное смысловое слово,
приводит его к словарной форме и показывает явное подтверждение:

```text
В словаре сохраняются только отдельные слова.

Kiezen → выбирать

Добавить это слово?

🆕 Добавить Kiezen
❌ Не добавлять
⬅️ Назад | #️⃣ Главная
```

До нажатия `🆕 Добавить …` слово не записывается. Если подходящее слово нельзя
выбрать уверенно, бот просит прислать нужное слово отдельно. Ответ внешнего
анализа дополнительно проверяется локально: многословный результат отклоняется.

Список нескольких слов можно прислать по одному слову в строке. Если хотя бы
одна строка является фразой, вместо пакетного сохранения бот предлагает одно
подходящее слово из всего ввода.

## Карточка слова

Карточка содержит термин и перевод в одной строке, часть речи, полезные формы,
короткий пример и, когда данные готовы, транскрипцию, смысл, нюанс и задание.
Одинаковая сохранённая карточка используется в словаре и в `Слове дня`.
У глагола дополнительно показывается компактное спряжение в настоящем времени.
Оно строится локально для нидерландского и английского, поэтому появляется и у
старых карточек сразу при открытии, без ожидания AI-пересборки.

```text
Het brein → Мозг
Разбор: существительное · het-слово
Множественное число: de breinen
💡 Полезно: Mijn brein heeft rust nodig → Моему мозгу нужен отдых
```

```text
Werken → Работать
Формы: werken · werkte · heeft gewerkt
Спряжение: ik werk · jij/u/hij werkt · wij/jullie/zij werken
```

Для нидерландских слов доступно прослушивание. Повторное озвучивание использует
кэш, если он уже есть. Ошибка TTS не меняет и не удаляет карточку.

## Обновление карточки

На сохранённой карточке доступна кнопка:

```text
✨ Обновить
```

Она заново проверяет словарную форму, часть речи, артикль, перевод, описание и
формы именно сохранённого слова, а также запрашивает два примера в разных бытовых
ситуациях. Для явной пересборки старый результат анализа не используется из кэша.

Ручное обновление сразу пересобирает только выбранное слово через платную модель
OpenRouter и затем присылает готовую карточку без промежуточного сообщения.
`id`, дата добавления и SRS-прогресс сохраняются. Без успешного ответа старая карточка
остаётся доступной и не перезаписывается.

После обновления формата все старые слова автоматически ставятся в постоянную
очередь пересборки. Очередь сохраняется между перезапусками, обрабатывает не более
трёх карточек за проход и не очищается, пока не обновлено последнее слово.
Неполный ответ одного анализатора передаётся следующему резерву. На экране языка
видно количество оставшихся карточек, а после завершения бот присылает итог.
Старый callback массовой проверки совместимо запускает эту же безопасную очередь.
После полного внешнего отказа один пакет для каждого пользователя повторяется
через пять минут; одновременно выполняется не более одного пакета.

## Стартовая подборка

`✨ Подобрать новые слова` открывает частотный набор выбранного уровня:

- `🔽 Простой (A1–A2)`
- `🔼 Сложный (B1+)`

Пользователь отмечает нужные слова и подтверждает добавление. Многословные
legacy-позиции из старого каталога пропускаются. Старые callback-и подбора фраз
открывают обычную подборку слов.

## Старые данные

Ранее сохранённые фразы и предложения не удаляются из PostgreSQL или memory
fallback. Они считаются архивными и скрыты:

- не входят в количество слов;
- не показываются в категориях и поиске;
- не попадают в тренажёр;
- не выбираются как материал дня;
- не отправляются на фоновую перепроверку словаря.

Это сохраняет пользовательские данные и позволяет провести отдельную миграцию в
будущем без риска потери записей.

Одиночное слово с ошибочной старой меткой `фраза` не скрывается: форма термина
имеет приоритет, а фоновая проверка исправляет его часть речи.

## Хранение и надёжность

Нидерландские и английские слова лежат в общем пользовательском списке с полем
языка. PostgreSQL KV используется при наличии `DATABASE_URL`, иначе работает
in-memory fallback.

Фоновое техническое обслуживание локально нормализует данные и ставит устаревшие
карточки в отдельную миграцию; само обслуживание AI не вызывает. Миграция идёт
небольшими пакетами только при отсутствии активных пользовательских действий и
использует общую цепочку резервных AI. Пока миграция не закончена, необязательные
AI-прогревы главных экранов и новостей уступают ей квоту. Если новое иностранное
слово сохранено во время полного сбоя провайдеров, оно сразу появляется в словаре
и одновременно попадает в постоянную очередь анализа. `id`, дата добавления и
SRS-прогресс при последующем обновлении не меняются.

AI вызывается только для перевода, нормализации, выбора слова из свободного
текста и содержательного разбора. Меню, категории, сортировка, дубликаты,
пагинация и фильтрация архивных фраз работают локально.

Перед последней попыткой OpenRouter словарь использует прямой резерв Mistral.
Сбой, лимит, пустой или непригодный JSON любого предыдущего провайдера передаёт
пакет Mistral; сохранение и формат карточки проходят ту же локальную проверку.
Во внешние резервы передаются только публичные данные карточки без идентификатора
пользователя и личного профиля.
Внутри последней попытки OpenRouter используется упорядоченный список
`OPENROUTER_MODELS`: если первая модель не отвечает, OpenRouter пробует следующую
разрешённую production Guardrail модель.
