# 👾 Игры

## Назначение

Раздел открывается прямо из главного меню и сразу показывает одну игру под выбранные
платформы. Отдельной анкеты первого входа нет.

## Как это работает

Карточка содержит платформы, жанр, короткое описание, не больше двух причин попробовать
игру и один совет для старта. Кнопка `✨ Другая игра` предлагает следующий вариант без
недавних повторов. Обычный подбор работает по локальному каталогу и не расходует AI.

`🎭 По жанру` позволяет выбрать RPG, экшен, стратегию, приключение, уютную игру,
хоррор или настолку. Рекомендация учитывает одновременно жанр и платформы пользователя.

`🆕 Премьеры игр` показывает ближайшие релизы на выбранных платформах. Дата, платформа
и ссылка должны подтверждаться найденным источником; неподтверждённые записи отбрасываются.
Подборка кэшируется на неделю. Если актуальных подтверждённых данных нет, бот показывает
короткое честное сообщение без выдуманных релизов.

## Предпочтения

Платформы настраиваются через
`🎚️ Настройки` → `📝 Предпочтения` → `👾 Игры`:

- `💻 ПК`;
- `🎮 PS5`;
- `🎲 Настолки`;
- `🕹️ Прочее` — другие консоли и устройства.

Можно выбрать несколько вариантов. Пустой выбор означает все платформы. Изменение
сразу сбрасывает дневную рекомендацию; отдельная очистка данных не нужна.

## Навигация

Главная карточка содержит `✨ Другая игра`, `🆕 Премьеры игр`, `🎭 По жанру` и
`#️⃣ Главная`.
