# Ассистент

## Назначение

В чат можно написать обычной фразой вместо поиска нужной кнопки. Если действие
понятно, бот сразу запускает соответствующий сценарий; если нет — даёт короткий
свободный ответ или задаёт один вопрос.

## Быстрые действия

Ассистент распознаёт запросы о рецепте, холодильнике, образе, погоде, поездке,
кино, книгах, музыке, концертах, обучении, словаре, тревожной мысли и врачебном
вопросе. Медицинские сообщения передаются в сценарий «Врач» до обычного
свободного ответа.

Также можно написать:

- `добавь слово ...` или `добавь фразу ...`;
- `добавь в продукты ...`;
- `добавь лайфхак ...`;
- `добавь в любимые фильм/сериал/книгу/артиста/страну ...`.

У бота нет общего действия «сохранить заметку» и общего списка закладок.

## Ожидание и резерв

Для долгой карточки исходный экран остаётся в чате, а одна inline-кнопка
показывает текущий этап. Свободный ответ использует централизованный AI-маршрут
с короткими тайм-аутами и резервами. Если все провайдеры недоступны, бот завершает
ожидание понятным локальным ответом, а не оставляет бесконечную загрузку.

В личном свободном чате на актуальном Telegram сначала появляется временный
Rich Draft «Думаю…». Groq, GitHub Models и OpenRouter отдают текст потоком, а
черновик обновляется не чаще примерно двух раз в секунду; после завершения бот
всегда сохраняет один полноценный Rich Message с заголовком, списком или цитатой.
До первой буквы сохраняется обычный порядок резервов. Если уже видимый поток
оборвался, ответ не смешивается с другой моделью и предлагается коротко отправить
сообщение ещё раз. Служебные блоки рассуждений модели (`<think>…</think>`) не
попадают ни в черновик, ни в финальное сообщение, ни в историю чата — даже если
тег пришёл несколькими частями потока. При недоступности Rich API остаётся прежний редактируемый
индикатор ожидания и обычный ответ.

## Ограничения

- Короткие реплики вроде «ок» и «спасибо» получают короткий ответ без AI.
- Свободный ответ учитывает только недавний контекст чата.
- Неоднозначная команда может потребовать один уточняющий вопрос.
