# Детектив

## Назначение
«Детектив» — короткое упражнение на чтение внутри обучения языкам. Бот загадывает знакомый объект или персонажа, даёт связное описание на изучаемом языке, а пользователь пытается понять текст и угадать ответ.

## Как это работает
Пользователь нажимает `🕵️ Детектив` и сразу видит под текущей карточкой только inline-кнопку статуса `🕵️ Ищу загадку...`. Если поиск продолжается, статус меняется на `📖 Проверяю текст...`, затем на `🧩 Собираю загадку...`. Готовая загадка приходит отдельным сообщением, а кнопки старой карточки восстанавливаются. Уровень всегда лёгкий для всех: язык подсказок берётся автоматически из активного языка обучения в настройках.

Вместо списка улик игра показывает короткое связное описание на изучаемом языке. AI выбирает знакомое животное, блюдо, предмет, профессию, транспорт, место или очень известного героя. Описание состоит примерно из 3–4 связанных предложений и 25–45 слов, содержит 2–4 конкретных признака и не называет ответ. Метафоры, туманные формулировки, специальная информация и фактические ошибки отбрасываются.

Для учебного текста используется централизованный AI-маршрут с резервами. Если
генерация не дала подходящий результат, игра использует короткую локальную
загадку, которой ещё не было среди недавних реальных раундов. Пользователь
получает раунд, а не техническую ошибку.

Одна сильная подсказка генерируется сразу вместе с описанием; отдельного второго уровня подсказок нет. После использования кнопка подсказки исчезает. Текст игры и короткое объяснение идут на активном языке обучения. Кнопки остаются на русском: `💡 Подсказка`, `😞 Сдаюсь`, `⬅️ Назад`, `#️⃣ Главная`, `✨ Ещё`.

После правильного ответа игра ищет фотографию только по английскому названию ответа и берёт первый подходящий результат. Показывается только горизонтальная фотография: ширина должна быть больше высоты. Портретные, квадратные и изображения без надёжных размеров отбрасываются; если подходящего кадра нет, результат остаётся текстовым.

Пользователь отвечает текстом. Ответ засчитывается не только при точном совпадении, но и при небольшой опечатке, сокращении или совпадении одного из допустимых вариантов. После первой ошибки остаётся ещё одна попытка. После второй ошибки, правильного ответа или кнопки `Сдаюсь` показывается одна и та же полноценная карточка результата.

После завершения раунда доступна кнопка `✨ Ещё`, которая запускает новый лёгкий раунд на том же языке внутри текущей карточки.

## Основные возможности
- Автоматический язык подсказок: активный язык обучения из настроек.
- Один фиксированный лёгкий уровень.
- Одно связное описание и одна дополнительная подсказка.
- Проверка ответа с допуском на опечатки и варианты написания.
- Две попытки перед автоматическим раскрытием ответа.
- Кнопка `Сдаюсь` для мгновенного ответа с объяснением.
- Память о недавно загаданных темах, чтобы загадки не повторялись слишком часто.

## Настройки
Язык меняется в общих настройках обучения. Отдельной настройки сложности нет.

## Ограничения
- После двух ошибок бот раскрывает ответ, отменить это нельзя.
- Список недавно загаданных тем ограничен; старые темы со временем могут повториться.
- Нестрогая проверка ответа иногда может засчитать похожий, но неверный вариант.
- Подсказка только одна и после использования исчезает.
