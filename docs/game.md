# Угадай персонажа

## Назначение
«Угадай персонажа» — короткое упражнение на чтение внутри обучения языкам. Бот загадывает знакомый объект или персонажа, даёт связное описание на изучаемом языке, а пользователь пытается понять текст и угадать ответ.

## Как это работает
Пользователь нажимает `🕵️ Угадай персонажа` и сразу видит под текущей карточкой только inline-кнопку статуса `🕵️ Ищу загадку...`. Если поиск продолжается, статус меняется на `📖 Проверяю текст...`, затем на `🧩 Собираю загадку...`. Готовая загадка приходит отдельным сообщением, а кнопки старой карточки восстанавливаются. Уровень всегда лёгкий для всех: язык подсказок берётся автоматически из активного языка обучения в настройках.

Вместо списка улик игра показывает короткое связное описание на изучаемом языке. Перед ним есть понятная строка категории: `животное`, `еда`, `предмет`, `профессия`, `транспорт`, `место` или `герой`. AI выбирает знакомый объект из одной из этих категорий. Описание состоит примерно из 3–4 связанных предложений и 25–45 слов, содержит 2–4 конкретных признака и не называет ответ. Метафоры, туманные формулировки, специальная информация и фактические ошибки отбрасываются.

Для учебного текста используется централизованный AI-маршрут с резервами. Если
генерация не дала подходящий результат, игра использует короткую локальную
загадку, которой ещё не было у этого пользователя. История ответов и вариантов
названий не сокращается, поэтому уже сыгранная загадка не возвращается. Если
все локальные загадки уже сыграны, а новый уникальный раунд собрать не удалось,
бот честно предлагает попробовать позже, не повторяя прежний ответ.

Одна сильная подсказка генерируется сразу вместе с описанием; отдельного второго уровня подсказок нет. После использования кнопка подсказки исчезает. Текст игры и короткое объяснение идут на активном языке обучения. Кнопки остаются на русском: `💡 Подсказка`, `😞 Сдаюсь`, `⬅️ Назад`, `#️⃣ Главная`, `✨ Ещё`.

После правильного ответа игра ищет фотографию только по английскому названию ответа и берёт первый подходящий результат. Показывается только горизонтальная фотография: ширина должна быть больше высоты. Портретные, квадратные и изображения без надёжных размеров отбрасываются; если подходящего кадра нет, результат остаётся текстовым.

Пользователь отвечает текстом. Ответ засчитывается не только при точном совпадении, но и при небольшой опечатке, сокращении или совпадении одного из допустимых вариантов. После первой ошибки остаётся ещё одна попытка. После второй ошибки, правильного ответа или кнопки `Сдаюсь` показывается одна и та же полноценная карточка результата.

После описания есть пустая строка и понятная инструкция: «Напиши ответ следующим сообщением — можно на любом языке». Поэтому ответ можно дать на изучаемом языке, по-русски или по-английски — бот проверит сохранённые варианты. Отдельный повтор вопроса «Кто это?» после описания или подсказки не показывается.

После завершения раунда доступна кнопка `✨ Ещё`, которая запускает новый лёгкий раунд на том же языке внутри текущей карточки.

## Основные возможности
- Автоматический язык подсказок: активный язык обучения из настроек.
- Один фиксированный лёгкий уровень.
- Одно связное описание и одна дополнительная подсказка.
- Проверка ответа с допуском на опечатки и варианты написания.
- Две попытки перед автоматическим раскрытием ответа.
- Кнопка `Сдаюсь` для мгновенного ответа с объяснением.
- Память обо всех загаданных темах и вариантах их названий; уже сыгранный ответ не показывается повторно.

## Настройки
Язык меняется в общих настройках обучения. Отдельной настройки сложности нет.

## Ограничения
- После двух ошибок бот раскрывает ответ, отменить это нельзя.
- Если закончились локальные карточки и временно не удаётся собрать новый уникальный раунд, бот попросит попробовать позже.
- Нестрогая проверка ответа иногда может засчитать похожий, но неверный вариант.
- Подсказка только одна и после использования исчезает.
