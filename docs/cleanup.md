# Чистка списков

## Назначение

Это общий механизм просмотра и удаления элементов из личных списков. У него нет
своего пункта главного меню: он открывается из шкафа, холодильника, словаря,
чемодана, кино, книг или музыки.

## Как это работает

Обычный список показывает элементы постранично. Для личных коллекций Кино,
Книг, Музыки и Поездок кнопка `🆕 Добавить ...` находится сразу над строкой
`⬅️ Назад | #️⃣ Главная`. Настройки рекомендаций доступны отдельно через
`🎚️ Настройки` → `📝 Предпочтения`.

В режиме `✏️ Изменить` элемент отмечается `□` / `✅`. Затем пользователь
подтверждает удаление. Для одной вещи в шкафу и одной словарной записи сначала
открывается их карточка; удаление тоже требует подтверждения.

Удалённые фильмы, книги, артисты и страны не возвращаются в рекомендации.
Отдельных пользовательских списков «Скрытое», «Смотрел», «Прочитано», «Уже
знаю» и общих «Сохранений» нет.

## Ограничения

- На странице показывается до восьми элементов.
- Открытый экран чистки действует 24 часа; затем его нужно открыть снова.
- Если список успел измениться в другом действии, бот переоткрывает актуальные
  данные, а не удаляет элемент вслепую.
