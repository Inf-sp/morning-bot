# Дешёвые билеты

## Назначение
Уведомление о новых публикациях авиадилов — ошибочных тарифах и распродажах — с вылетом
из Амстердама (AMS). Бот сам цены не ищет и не сравнивает, авиационные API не использует:
он только читает ленты сайтов, которые такие предложения публикуют, и присылает ссылку на
исходную публикацию, чтобы быстро проверить билет.

## Источники
Список лент — `config.FLIGHT_DEAL_FEEDS`, env `FLIGHT_DEAL_FEEDS` в формате
`Название|RSS-URL` через запятую. По умолчанию:

| Источник | Лента | Статус |
|---|---|---|
| Secret Flying | `https://www.secretflying.com/feed/` (стандартная WordPress-лента) | не проверена с сервера |
| Fly4free | `https://www.fly4free.com/feed/` | не проверена с сервера |

Новый источник добавляется только после проверки, что у него есть RSS/Atom или другой
легальный способ получать публикации. Скрейпинг HTML и платные подписки (email-алерты
Secret Flying — тариф Standard) не используются. Если источник не отвечает или лента пустая,
в журнал сервиса пишется `flight_deals: feed unavailable` / `feed has no items`, состояние
пользователей не меняется.

## Как это работает
- `bot.job_flight_deals` — каждые 10 минут с 07:00 до 23:00 (`config.TZ`). Ленты читаются
  один раз на всех подписчиков. Публикации, вышедшие ночью, приходят утром, пока они ещё в ленте.
- Вылет из Амстердама определяется по заголовку: `Amsterdam`, `Schiphol` или `AMS` в части
  до « to » (`Amsterdam, Netherlands to …`, `Brussels or Amsterdam to …`) либо явное
  `from Amsterdam`. Перелёты *в* Амстердам не проходят.
- Дубли: id публикации (guid, иначе ссылка без utm-меток) хранится в профиле
  (`flight_deals.seen`, последние 400). Одна публикация на разных лентах с одинаковым id — одна.
- При первом включении текущая лента только запоминается — старые предложения пачкой не
  приходят. За одну проверку — не больше трёх новых, остальные приходят следующей проверкой.
- Скорость ограничена источником: если сайт обновляет ленту с задержкой, бот узнает о
  публикации не раньше. Мгновенность не гарантируется.

## Уведомление

```text
✈️ Дешёвый билет из Амстердама

Amsterdam → Hong Kong
от €201 · в одну сторону · Secret Flying

Такие цены держатся недолго — проверь даты и цену в публикации.
```

Если в заголовке есть «error fare», заголовок — `✈️ Ошибочный тариф из Амстердама`.
Город назначения и цена берутся из заголовка публикации без AI; не распознано — показывается
исходный заголовок. Кнопки: `Открыть публикацию` (ссылка на исходный пост), ниже
`🎚️ Настроить | #️⃣ Главная`.

## Настройки
`🎚️ Настройки → 🔔 Уведомления → Дешёвые билеты · из Амстердама`. Только для пользователей
с городом в Нидерландах, по умолчанию выключено, времени нет — приходит при публикации.
