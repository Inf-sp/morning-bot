# Музыка и концерты

## Назначение
Этот раздел открывается прямо из главного меню витриной недели: ближайшие концерты любимых артистов и заметные новые альбомы. «🎫 Концерты», «🎚️ Мои артисты» и предпочтения находятся внутри Музыки.

## Как это работает
При входе бот показывает «🎧 Музыка этой недели»: до трёх ближайших подтверждённых концертов любимых артистов и до четырёх альбомов, которые вышли на этой неделе и уже вошли в региональный чарт Apple Music. Релизы обновляются раз в день; это не AI-подбор и не случайный список малоизвестных артистов.

Сценарий `✨ Подобрать музыку` начинается со списка любимых исполнителей, который указывает пользователь. На его основе бот подбирает одного нового исполнителя, максимально близкого по звучанию, добавляет короткое описание, пояснение «почему зайдёт», несколько треков, с которых стоит начать, и интересный факт.

Язык обучения не влияет на подбор. Предпочтение отдаётся активным, популярным или признанным в своей сцене артистам с выразительной мелодичной музыкой, а не случайным малоизвестным именам. Музыкальный подбор использует профиль вкуса и utility-модель; Tavily и общий web-search для него не запускаются. Уже показанные, любимые и отклонённые артисты не предлагаются повторно. Если AI-цепочка временно недоступна, бот показывает нового артиста из локального проверенного каталога вместо ошибки.

Концерты ищутся через Ticketmaster. Обычная афиша и фоновое обновление не запускают web-search по каждому любимому артисту. Внешний поиск допускается только как редкий последний fallback, когда пользователь вручную ищет одного конкретного артиста, а Ticketmaster его не нашёл. Ticketmaster-запросы идут последовательно: при первом `429` бот сразу сохраняет общий cooldown (учитывая `Retry-After`) и не запускает оставшихся артистов из текущей очереди. Этот cooldown общий для задач и Railway-реплик; фоновая проверка не считает сервис восстановленным — восстановление фиксируется только после успешного реального поиска. Найденные страницы бот честно читает и извлекает из них дату, площадку, город, формат события и ссылки — событие добавляется только если основные данные прямо подтверждены текстом страницы, ничего не додумывается. Карточка отдельно сообщает, выступает артист с собственным концертом или на фестивале; для фестиваля показывает его название. В актуальном Telegram карточка ближайших концертов отображается блоками, а подтверждённая дата локализуется на устройстве; обычная текстовая карточка остаётся доступной как fallback. Результаты кэшируются: Ticketmaster-подборка по стране — на неделю, внешний поиск одного артиста — тоже на неделю и глобально. Из результатов исключаются трибьют-шоу, кавер-концерты и похожие имитации — остаются только выступления самого артиста.

Отдельно есть еженедельная проверка: раз в неделю (по пятницам в 10:00, вместе с афишей недели — плановое уведомление «Куда сходить») бот обновляет список концертов и сравнивает его с тем, что видел раньше. Если появился новый концерт кого-то из любимых исполнителей — добавляет его в то же сообщение отдельным блоком; если ничего нового не появилось, показывается только афиша, без лишнего блока. При самом первом включении этой проверки бот просто запоминает текущие концерты как «уже видел» и ничего не присылает — иначе первый запуск показал бы всю афишу как «новое».

## Основные возможности
- Главный экран: витрина `🎧 Музыка этой недели`, затем `✨ Подобрать музыку`, `🎭 По жанру` и отдельной строкой `🎫 Концерты`; ниже `🎚️ Мои артисты`, затем одна кнопка `#️⃣ Главная`. В списке `🎚️ Мои артисты` первой находится `📌 Предпочтения`, затем любимые исполнители из базы.
- «🎧 Музыка для тебя» — один новый исполнитель под вкус, с описанием звучания, объяснением сходства и рекомендованными треками.
- При замене текущая карточка остаётся на месте, а под ней временно показывается только статус поиска. Готовый новый исполнитель приходит отдельным сообщением, после чего под старой карточкой восстанавливаются обычные кнопки.
- Кнопки под карточкой: «✨ Другой артист» — широкая строка сверху, показывает другого исполнителя, отклонённый уходит в чёрный список; ниже — «🎫 Концерты», «🎭 По жанру» и «🎚️ Мои артисты».
- `🎭 По жанру` открывает быстрый выбор: инди, поп, электроника, R&B, рок или хип-хоп. Следующий артист и замена остаются внутри выбранного жанра.
- Отклонённые, знакомые и удалённые исполнители попадают в общую внутреннюю категорию «Не рекомендовать» и не повторяются; отдельных кнопок «Скрытое» и «Уже знаю» нет.
- Переход к настройкам любимых стилей из списка `🎚️ Мои артисты`.
- Поиск концертов любимых исполнителей в выбранной стране на ближайший год, с ценой, местом и датой; если событие найдено не через Ticketmaster, карточка показывает, откуда оно взято (сайт исполнителя, сайт площадки, билетный сервис).
- Возможность сменить страну поиска концертов из списка популярных европейских стран.
- Плановое уведомление «Куда сходить» (по пятницам в 10:00) — афиша недели (концерты любимых артистов + ближайшие кинопремьеры) и, если появилось что-то новое, новые концерты любимых исполнителей — одним сообщением.

## Настройки
- В первой кнопке `📌 Предпочтения` внутри `🎚️ Мои артисты` можно выбрать любимые стили: инди, поп, электронику, R&B, рок и хип-хоп. Экран показывает только кнопки стилей, без служебных разделителей. Обычный подбор учитывает их вместе с любимыми артистами; кнопка `🎭 По жанру` временно задаёт конкретный жанр для одного подбора.
- Список любимых исполнителей можно пополнять вручную кнопкой `🆕 Добавить артиста` над навигацией. Режима `✏️ Изменить` в этом списке нет.
- Список исполнителей, которые уже знакомы или не понравились — не будут предлагаться повторно.
- Страна для поиска концертов — выбирается из списка (Нидерланды, Бельгия, Германия, Франция, Великобритания, Испания, Италия, Австрия, Швейцария, Польша, Швеция, Дания, Португалия), по умолчанию берётся страна из общих настроек профиля.
- Новые концерты любимых артистов показываются автоматически внутри «Куда сходить»; отдельного переключателя «вкл/выкл» в коде нет, работа привязана к наличию списка любимых артистов и ключа доступа к внешнему сервису.

## Ограничения
- «Музыка для тебя» работает и без списка любимых артистов: тогда бот начинает с известного современного исполнителя и не повторяет уже показанное. Для персонального подбора и афиши концертов полезно добавить любимых артистов.
- Поиск концертов требует включённого доступа к внешнему сервису по продаже билетов; если он не настроен, бот честно сообщает, что функция недоступна, вместо того чтобы показывать пустой список.
- Результаты по одной и той же стране обновляются не чаще раза в неделю (используется недельный кэш) — сразу после смены страны первый запрос может занять время, а следующие несколько дней будут показывать одни и те же данные.
- Трибьют-концерты, кавер-шоу и похожие «имитации» исполнителя намеренно скрываются из результатов.
- Список стран для поиска концертов ограничен Европой — другие регионы не поддерживаются.
- Если внешний сервис долго не отвечает или превышен лимит запросов, часть исполнителей может временно не попасть в список концертов — бот не переспрашивает бесконечно, чтобы не заблокировать всю проверку.
- Внешний поиск (не Ticketmaster) добавляет событие только если дата, исполнитель и площадка прямо подтверждены найденной страницей — если подтверждения нет, событие просто не попадает в список, без догадок.
- "Соседние регионы" для внешнего поиска — заранее заданный список географических соседей внутри той же группы европейских стран, что поддерживает поиск концертов, а не полная карта всех границ мира.
