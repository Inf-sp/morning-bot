# Музыка и концерты

## Назначение
Этот раздел открывается прямо из главного меню ежедневной витриной: трек под настроение,
ребус, именинник из музыки, до трёх ближайших концертов и короткая строка «Интересно». «🎫 Концерты», «🎚️ Мои
артисты» находятся внутри Музыки; стили выбираются в общих предпочтениях.

## Как это работает

Названия блоков ежедневной витрины (ребус, именинник, концерты и «Интересно») выделяются жирным; содержание после двоеточия остаётся обычным текстом. Именинник расположен сразу перед «Интересно».

При входе бот показывает «🎧 Музыка этой недели · {город}». В ней есть «Музыкальный ребус»
со скрытым ответом, «Именинник дня» — родившийся сегодня заметный музыкант, до трёх ближайших подтверждённых концертов любимых
исполнителей и связанная с ребусом строка «Интересно». Концерты показаны отдельными пунктами: `• Артист - Дата · Город`.
Чарты и списки новых альбомов на главном экране не
показываются.

Ребус меняется по календарной дате. Музыкальный именинник показывает дату и год рождения, проверяется через Wikidata
один раз в сутки и кэшируется глобально; при временной недоступности источника бот не
придумывает дату рождения. Ответ ребуса использует нативный spoiler Telegram.

Сценарий `✨ Подобрать новую музыку` начинается с отмеченных жанров в `🎚️ Настройки` → `📌 Предпочтения` → `🎧 Музыка`. Бот рекомендует артиста только из этих жанров; при пустом выборе вместо рекомендации сразу просит отметить хотя бы один стиль. Любимые исполнители уточняют подбор внутри выбранных жанров. Карточка содержит короткое описание, пояснение «почему зайдёт», несколько треков, с которых стоит начать, и интересный факт.

Язык обучения не влияет на подбор. Предпочтение отдаётся активным, популярным или признанным в своей сцене артистам с выразительной мелодичной музыкой, а не случайным малоизвестным именам. Музыкальный подбор использует профиль вкуса и utility-модель; Tavily и общий web-search для него не запускаются. Уже показанные, любимые и отклонённые артисты не предлагаются повторно. Если AI-цепочка временно недоступна, бот показывает нового артиста из локального проверенного каталога вместо ошибки.

Концерты сперва ищутся через Ticketmaster, а если артист там не найден — через ограниченный резервный поиск подтверждённых страниц. И ежедневная витрина Музыки, и обычная афиша используют одну и ту же цепочку: так ближайшее подтверждённое выступление не пропадает с главного экрана. Ticketmaster-запросы идут последовательно: при первом `429` бот сразу сохраняет общий cooldown (учитывая `Retry-After`) и не запускает оставшихся артистов из текущей очереди. Этот cooldown общий для задач и Railway-реплик; фоновая проверка не считает сервис восстановленным — восстановление фиксируется только после успешного реального поиска. Найденные страницы бот честно читает и извлекает из них дату, площадку, город, формат события и ссылки — событие добавляется только если основные данные прямо подтверждены текстом страницы, ничего не додумывается. Карточка отдельно сообщает, выступает артист с собственным концертом или на фестивале; для фестиваля показывает его название. Экран концертов показывает все найденные выступления в пределах ближайшего года, без служебной строки о подтверждении. Кнопка страны всегда содержит флаг и полное название. Результаты кэшируются: подборка по стране — на неделю, а устаревшие результаты прежней цепочки автоматически не используются. Из результатов исключаются трибьют-шоу, кавер-концерты и похожие имитации — остаются только выступления самого артиста.

Отдельно есть еженедельная проверка: раз в неделю (по пятницам в 10:00, вместе с афишей недели — плановое уведомление «Куда сходить») бот обновляет список концертов и сравнивает его с тем, что видел раньше. Если появился новый концерт кого-то из любимых исполнителей — добавляет его в то же сообщение отдельным блоком; если ничего нового не появилось, показывается только афиша, без лишнего блока. При самом первом включении этой проверки бот просто запоминает текущие концерты как «уже видел» и ничего не присылает — иначе первый запуск показал бы всю афишу как «новое».

## Основные возможности
- Главный экран: витрина `🎧 Музыка этой недели · {город}`, затем `✨ Подобрать новую музыку`, `🎭 По жанру`, `🎫 Концерты`, `🎚️ Мои артисты` и `#️⃣ Главная`. Жанры в меню `🎭 По жанру` показываются только из отмеченных стилей. В списке `🎚️ Мои артисты` находятся любимые исполнители из базы.
- «🎧 Музыка для тебя» — один новый исполнитель под вкус, с описанием звучания, объяснением сходства и 2–3 рекомендованными треками. Название каждого трека ведёт на подтверждённый трек в YouTube Music; если точный результат не найден, открывается поиск этого трека и исполнителя в YouTube Music. После каждого названия остаётся короткая пометка, а предпросмотр ссылок Telegram отключён.
- При замене текущая карточка остаётся на месте, а под ней временно показывается только статус поиска. Готовый новый исполнитель приходит отдельным сообщением, после чего под старой карточкой восстанавливаются обычные кнопки.
- Кнопки под карточкой: «✨ Другой артист» — широкая строка сверху, показывает другого исполнителя, отклонённый уходит в чёрный список; ниже — «🎫 Концерты», «🎭 По жанру» и «🎚️ Мои артисты».
- `🎭 По жанру` открывает быстрый выбор: инди, поп, электроника, R&B, рок или хип-хоп. Следующий артист и замена остаются внутри выбранного жанра.
- Отклонённые, знакомые и удалённые исполнители попадают в общую внутреннюю категорию «Не рекомендовать» и не повторяются; отдельных кнопок «Скрытое» и «Уже знаю» нет.
- Любимые стили меняются через `🎚️ Настройки` → `📌 Предпочтения` → `🎧 Музыка`.
- Поиск концертов любимых исполнителей в выбранной стране на ближайший год, с ценой, местом и датой. На кнопке текущей страны — её флаг и полное название. Внизу списка доступны `⬅️ Назад` в Музыку и `#️⃣ Главная`; в выборе страны `⬅️ Назад` возвращает к списку концертов.
- Возможность сменить страну поиска концертов из списка популярных европейских стран.
- Плановое уведомление «Куда сходить» (по пятницам в 10:00) — афиша недели (концерты любимых артистов + ближайшие кинопремьеры) и, если появилось что-то новое, новые концерты любимых исполнителей — одним сообщением.

## Настройки
- В `🎚️ Настройки` → `📌 Предпочтения` → `🎧 Музыка` можно выбрать любимые стили: инди, поп, электронику, R&B, рок и хип-хоп. Экран показывает только кнопки стилей, без служебных разделителей. Обычный подбор учитывает их вместе с любимыми артистами; кнопка `🎭 По жанру` временно задаёт конкретный жанр для одного подбора.
- Список любимых исполнителей можно пополнять вручную кнопкой `🆕 Добавить артиста` над навигацией. Режима `✏️ Изменить` в этом списке нет.
- Список исполнителей, которые уже знакомы или не понравились — не будут предлагаться повторно.
- Страна для поиска концертов — выбирается из списка (Нидерланды, Бельгия, Германия, Франция, Великобритания, Испания, Италия, Австрия, Швейцария, Польша, Швеция, Дания, Португалия), по умолчанию берётся страна из общих настроек профиля.
- Новые концерты любимых артистов показываются автоматически внутри «Куда сходить»; отдельного переключателя «вкл/выкл» в коде нет, работа привязана к наличию списка любимых артистов и ключа доступа к внешнему сервису.

## Ограничения
- «Музыка для тебя» работает и без списка любимых артистов: тогда бот начинает с известного современного исполнителя и не повторяет уже показанное. Для персонального подбора и афиши концертов полезно добавить любимых артистов.
- Поиск концертов требует включённого доступа к внешнему сервису по продаже билетов; если он не настроен, бот честно сообщает, что функция недоступна, вместо того чтобы показывать пустой список.
- Результаты по одной и той же стране обновляются не чаще раза в неделю (используется недельный кэш) — сразу после смены страны первый запрос может занять время, а следующие несколько дней будут показывать одни и те же данные.
- Трибьют-концерты, кавер-шоу и похожие «имитации» исполнителя намеренно скрываются из результатов.
- Список стран для поиска концертов ограничен Европой — другие регионы не поддерживаются.
- Если внешний сервис долго не отвечает или превышен лимит запросов, часть исполнителей может временно не попасть в список концертов — бот не переспрашивает бесконечно, чтобы не заблокировать всю проверку.
- Внешний поиск (не Ticketmaster) добавляет событие только если дата, исполнитель и площадка прямо подтверждены найденной страницей — если подтверждения нет, событие просто не попадает в список, без догадок.
- "Соседние регионы" для внешнего поиска — заранее заданный список географических соседей внутри той же группы европейских стран, что поддерживает поиск концертов, а не полная карта всех границ мира.
