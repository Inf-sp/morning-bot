# Музыка и концерты

## Назначение
Музыка входит в хаб «🍿 Досуг» (см. `docs/leisure.md`); отдельного главного экрана Музыки нет. Рекомендация артиста открывается кнопкой хаба `🎧 Музыка`, концерты — через `🆕 Премьеры и концерты` → `🎫 Концерты`, любимые артисты — через `🎚️ Моя библиотека` → `🎧 Музыка`. Ближайшие концерты любимых артистов (до трёх) показываются блоком `Концерты:` прямо в хабе. Концерты всегда идут по дате: от ближайшего к более поздним. Афиша проверяется автоматически ночным прогревом хаба (только если персональный кэш концертов устарел) и перед пятничной подборкой событий; для одного артиста внешний поиск всё равно выполняется не чаще установленного месячного срока.

## Как это работает

`🎧 Музыка` открывает артиста дня из дневного кэша; `✨ Другой артист` под карточкой запускает новый живой подбор в том же жанре, не скрывая текущего артиста.
Если AI временно недоступен, подбор использует проверенный локальный пул выбранного жанра. После показа всего пула начинается новый цикл без немедленного повтора последнего артиста; любимые и явно отклонённые исполнители в резерв не возвращаются. Добавление артиста из карточки сразу показывает следующую рекомендацию в том же жанре.

Имя артиста в списке концертов ведёт прямо на подтверждённую страницу продажи билетов. Если ссылки нет, имя остаётся обычным текстом. В экране «🎫 Концерты» ссылка спрятана в имени исполнителя; отдельной строки `Подробнее…` нет. Остальная карточка показывает тип события и `Концерт: дата · город`. Чарты и списки новых альбомов не показываются.

Подбор начинается с жанров, отмеченных через `📝 Выбрать предпочтения` в `🎚️ Мои артисты`. Бот рекомендует артиста только из этих жанров; при пустом выборе вместо рекомендации сразу просит отметить хотя бы один стиль. Любимые исполнители уточняют подбор внутри выбранных жанров. Карточка содержит короткое описание, пояснение «почему зайдёт», несколько треков, с которых стоит начать, и интересный факт.

Язык обучения не влияет на подбор. Предпочтение отдаётся активным, популярным или признанным в своей сцене артистам с выразительной мелодичной музыкой, а не случайным малоизвестным именам. Музыкальный подбор одним AI-запросом получает до трёх кандидатов и выбирает первого подходящего локально; повторные полные генерации для отклонённого жанра не выполняются. Профиль вкуса используется как недоверенные данные, а не как инструкции модели. Tavily и общий web-search для подбора не запускаются. Уже показанные, любимые и отклонённые артисты не предлагаются повторно. Если AI-цепочка временно недоступна, бот показывает нового артиста из локального проверенного каталога в том же жанре вместо ошибки; для каждого стиля есть несколько вариантов.

Концерты сперва ищутся через Ticketmaster, а если артист там не найден — через ограниченный резервный поиск подтверждённых страниц. Новый добавленный артист проверяется сразу. Для остальных артистов поиск выполняется не чаще раза в месяц; если в выбранной стране уже найден будущий концерт, этого артиста не запрашивают повторно до тех пор, пока не пройдёт его последний известный концерт. Хаб «Досуг», экран концертов и пятничная подборка используют один и тот же сохранённый результат. Ticketmaster-запросы идут последовательно, не чаще двух в секунду, небольшими пакетами до восьми артистов, но один запуск проходит весь список любимых исполнителей. В статус «проверен» попадают только артисты с успешным ответом. При первом `429` бот сразу сохраняет общий cooldown (учитывая `Retry-After`) и оставляет непроверенных артистов в очереди. Этот cooldown общий для задач и Railway-реплик; фоновая проверка не считает сервис восстановленным — восстановление фиксируется только после успешного реального поиска. Найденные страницы бот честно читает и извлекает из них дату, площадку, город, формат события и ссылки — событие добавляется только если основные данные прямо подтверждены текстом страницы, ничего не додумывается. Карточка отдельно сообщает, выступает артист с собственным концертом или на фестивале; для фестиваля показывает его название. Экран концертов показывает все найденные выступления в пределах ближайшего года, без служебной строки о подтверждении. Кнопка страны всегда содержит флаг и полное название. Из результатов исключаются трибьют-шоу, кавер-концерты и похожие имитации — остаются только выступления самого артиста.

По пятницам в 10:00 приходит одно плановое уведомление `🎲 Ближайшие события`.
Оно объединяет кино, концерты и книги: в блоках кино и книг не больше
трёх пунктов, а в концертах — до шести ближайших неповторяющихся афиш на два месяца,
включая крупные события. Каждый пункт занимает одну строку. Название ведёт на трейлер или
страницу источника; рядом остаются только доступные жанр, оценка, дата или платформа,
без описания. Под сообщением находятся кнопки `🎬 Кино`, `🎫 Концерты`, `📚 Книги`,
`👾 Игры` и `#️⃣ Главная`. Премьерные витрины и концерты готовятся заранее, поэтому
сама рассылка использует сохранённые результаты. Первая широкая кнопка
`🔕 Отключить уведомления` выключает только пятничную подборку; кнопки категорий идут
отдельными широкими строками, а `#️⃣ Главная` находится внизу.

## Основные возможности
- «🎧 Музыка для тебя» — один новый исполнитель под вкус, с описанием звучания, объяснением сходства и 2–3 рекомендованными треками. Название каждого трека ведёт на подтверждённый трек в YouTube Music; если точный результат не найден, открывается поиск этого трека и исполнителя в YouTube Music. После каждого названия остаётся короткая пометка, а предпросмотр ссылок Telegram отключён.
- При замене текущая карточка остаётся на месте, а под ней временно показывается только статус поиска. Готовый новый исполнитель приходит отдельным сообщением, после чего под старой карточкой восстанавливаются обычные кнопки.
- Кнопки под карточкой: первой — красная `Не нравится` (артист уходит в стоп-лист, сразу следующий), затем `✨ Другой артист` (стандартного цвета) и `⬅️ Назад` в хаб «🍿 Досуг» | `#️⃣ Главная`. «Другой артист» меняет кнопки под карточкой на выбор «Новинка / отмеченные стили» (см. «Карточки рекомендаций» в `docs/leisure.md`).
- Выбор жанра показывает инди, поп, электронику, R&B, рок или хип-хоп из отмеченных стилей, по одному в строке, стандартными кнопками без цвета; следующий артист остаётся внутри выбранного жанра.
- Отклонённые, знакомые и удалённые исполнители попадают в общую внутреннюю категорию «Не рекомендовать» и не повторяются; отдельных кнопок «Скрытое» и «Уже знаю» нет.
- Любимые стили меняются кнопкой `📝 Выбрать предпочтения` (синяя, над «Назад | Главная») внутри `🎚️ Мои артисты`.
- Поиск концертов любимых исполнителей в выбранной стране на ближайший год, с ценой, местом и датой. На кнопке текущей страны — её флаг и полное название. Концерты открываются из «🎚️ Настроить» (Моя библиотека) → `🎫 Концерты`; внизу списка доступны `⬅️ Назад` в библиотеку и `#️⃣ Главная`; в выборе страны `⬅️ Назад` возвращает к списку концертов. Список, выбор страны и смена страны меняют текущий экран на месте, без нового сообщения; если свежего кэша нет, экран на время поиска показывает «⏳ Проверяю афишу…».
- Возможность сменить страну поиска концертов из списка популярных европейских стран.
- Плановое уведомление `🎲 Ближайшие события` по пятницам в 10:00 — до трёх строк с кино, концертами и книгами и быстрые переходы во все три категории.

## Настройки
- Через `📝 Выбрать предпочтения` в `🎚️ Мои артисты` можно выбрать любимые стили: инди, поп, электронику, R&B, рок и хип-хоп. Экран показывает только кнопки стилей, без служебных разделителей. Обычный подбор учитывает их вместе с любимыми артистами; кнопка `🎭 Выбрать жанр` временно задаёт конкретный жанр для одного подбора.
- Текст экрана — одна строка «🎚️ Мои артисты · N артистов»; сами исполнители — кнопками, разбитыми по жанрам; внутри жанра имена идут по алфавиту. Категория `Без жанра` не показывается: артисты без подтверждённого стиля остаются доступны в нейтральной группе `Другие артисты`. Список можно пополнять вручную кнопкой `✅ Добавить артиста` над навигацией. Premium AI разбирает неоднозначное имя и показывает до трёх вариантов с коротким отличительным признаком; сохраняется только явно выбранный артист. После добавления бот показывает карточку с именем артиста и стилями, которые учтёт в следующих рекомендациях, с переходом обратно в `🎚️ Мои артисты`. Режима `✏️ Изменить` в этом списке нет.
- Имя исполнителя в базе — чистое имя без эмодзи и Telegram-разметки; старые записи
  автоматически очищаются. Оригинальное написание имени сохраняется, потому что это
  собственное имя, а не служебная подпись.
- Список исполнителей, которые уже знакомы или не понравились — не будут предлагаться повторно.
- Страна для поиска концертов — выбирается из списка (Нидерланды, Бельгия, Германия, Франция, Великобритания, Испания, Италия, Австрия, Швейцария, Польша, Швеция, Дания, Португалия), по умолчанию берётся страна из общих настроек профиля.
- Концерты любимых артистов и крупные события входят в общий блок `🎫 Концерты` пятничной подборки; отдельного уведомления о новых концертах нет. Вся подборка управляется переключателем `Ближайшие события`.

## Ограничения
- «Музыка для тебя» работает и без списка любимых артистов: тогда бот начинает с известного современного исполнителя и не повторяет уже показанное. Для персонального подбора и афиши концертов полезно добавить любимых артистов.
- Поиск концертов требует включённого доступа к внешнему сервису по продаже билетов; если он не настроен, бот честно сообщает, что функция недоступна, вместо того чтобы показывать пустой список.
- Результаты по одной и той же стране обновляются не чаще раза в месяц. Новый добавленный артист — исключение: его бот проверяет сразу. Если у артиста уже есть будущая дата в этой стране, повторная проверка ждёт, пока она пройдёт.
- Трибьют-концерты, кавер-шоу и похожие «имитации» исполнителя намеренно скрываются из результатов.
- Список стран для поиска концертов ограничен Европой — другие регионы не поддерживаются.
- Если внешний сервис долго не отвечает или превышен лимит запросов, часть исполнителей может временно не попасть в список концертов — бот не переспрашивает бесконечно, чтобы не заблокировать всю проверку.
- Внешний поиск (не Ticketmaster) добавляет событие только если дата, исполнитель и площадка прямо подтверждены найденной страницей — если подтверждения нет, событие просто не попадает в список, без догадок.
- "Соседние регионы" для внешнего поиска — заранее заданный список географических соседей внутри той же группы европейских стран, что поддерживает поиск концертов, а не полная карта всех границ мира.

История артистов нормализуется единообразно: дубли регистра объединяются, новый
артист сохраняется в конце истории, текущий не выбирается первым после полного круга.
